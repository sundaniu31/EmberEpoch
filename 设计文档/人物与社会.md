## 一、玩家权限、人物身份与状态

玩家是没有肉身、人物属性和寿命的国家最高决策者。人物可以信任、亲近、尊重或怨恨玩家，玩家通过经营、任用、交谈与回应诉求参与故事。

玩家决定具体人物的任命、免职与调任，以及建筑选址、建造、升级、拆除、启停、配方、生产目标、用工目标和公共预算；正式任务的对象、目标、执行者、投入与授权同样由玩家决定。人物可以提供意见、举荐、解释、提出条件或请求，采纳后才由玩家改变安排。人物的能力影响既定条件下的执行质量、耗时、损耗、成本、风险及适用的附加成果，不能自行改换任务对象、挪用其他建筑人手、扩大预算或签署越权协议。

人物状态分别记录，不堆成一项综合效率：

| 状态 | 内容与作用 |
|---|---|
| 通用能力与相关经历 | 怎样处理事情，实际做过什么、掌握哪些方法；支持跨岗任用 |
| 性格与价值取向 | 在乎什么、怎样表达和权衡；操守属于价值取向，野心属于动机 |
| 当前情绪 | 因具体原因产生的自豪、担忧、愤怒、悲伤等，可以并存 |
| 有向人际关系 | 本人对另一人的信任、亲近、尊重，双方分别记录 |
| 记忆与履历 | 任职、共同经历、重要选择、帮助、伤害及当时理解 |
| 诉求与个人目标 | 希望改善什么、怎样争取、何时算回应或完成 |

名望另作社会评价与曝光记录，不等于专业能力或任命硬门槛。能力强的人可以难相处，可靠的人也可能不擅长当前工作。个人情绪、任职表现和群体民意各有原因；主管生气不会直接令全体工人扣同样民意或触发全国惩罚，集体反应需要实际待遇、供给、工作环境或相关集体经历支撑。

采用个人中心和轻量亲属背景，保留父母、兄弟姐妹、亲子、婚姻、师徒、朋友和对手等实际关系。身份不直接决定亲近或立场；亲属会依据各自经历作出不同反应。不设家族集体情绪、统一忠诚、岗位配额、家族产业控制或公共职务世袭。岗位不是人物存续名额，离任者仍可作为朋友、亲属或事件参与者存在，不因腾出岗位删除其历史。

## 二、五项通用能力与十一类职责

| 能力 | 含义与边界 |
|---|---|
| 分析 | 理解信息、发现规律、判断原因和比较风险；只使用本人实际所知，不等于全知或自动识破谎言 |
| 统筹 | 安排流程、分配注意力、协调多人合作；在玩家目标、配置和授权内改善执行 |
| 交涉 | 理解对方、清楚表达、说服和争取合作，也用于教学与工作沟通；不保证接受或真实答复 |
| 应变 | 面对突发情况采取有效措施；不借此改变玩家目标、经营配置或授权 |
| 学习 | 吸收知识、掌握方法、迁移经验，影响陌生事务的适应；不是全部岗位的即时增产倍率 |

| 岗位职责 | 常见主要能力 | 可以影响的相关结果 |
|---|---|---|
| 农业主管 | 统筹、应变 | 农事组织、损耗控制、异常处理 |
| 矿业主管 | 分析、统筹 | 开采组织、问题排查、资源损耗 |
| 林业主管 | 统筹、应变 | 采伐组织、木材利用、现场处置 |
| 工业主管 | 统筹、分析 | 工序衔接、质量、交付稳定性 |
| 商业主管 | 分析、交涉 | 交易条件、成本与风险判断 |
| 军事主管 | 统筹、应变 | 征募编组、命令执行、部队协同 |
| 教育主管 | 交涉、统筹 | 讲解与培养、教学组织 |
| 宗教主管 | 交涉、统筹 | 仪式组织、信仰交流、争议处理 |
| 情报主管 | 分析、应变 | 线索研判、报告质量、任务风险 |
| 外交主管 | 交涉、分析 | 谈判表现、争端处理、授权内的附加成果 |
| 科研主管 | 分析、学习 | 新方法掌握、研究与验证质量 |

此表是定性作用范围，不是固定权重，也不表示同一任务同时获得所有效果。日常组织、问题调查和事故处置可分别侧重统筹、分析和应变；最终结果还取决于资源、环境与实际协作。主管和执行者只作用于实际承担的环节，不重复叠加同一种全任务综合倍率。

经历体现对事务、条件和方法的熟悉程度，与通用能力分开。科研形成的资料比较方法可能支持贸易研判，但不会凭空带来全部金融知识或出色谈判。调任不清空能力和经历，不设行业专属能力条、统一跨行业资格门槛或永久出身惩罚。

工厂职责称工业，科技与学术研究职责称科研，教育单独保留。十一类职责不是十一条经济产业链、固定十一人或开局同时开放；六个经济行业的统计口径见[产业与建设](产业与建设.md)，不因人事分类新增行业。军事主管职责不恢复部队训练，具体军队规则见[军事与占领](军事与占领.md)。

## 三、岗位、派遣、随行与调任

**一人只担任一个正式岗位，主管岗和专门执行岗均计入。** 任务是任职期间的一次工作，不是每次重新任命，也不能用临时头衔绕过一人一岗。

外交与情报先区分主管和专门执行人员，分别由玩家任命：外交主管准备资料、协调与汇总，使节承担出使、交流、谈判和现场应对；情报主管整理线索、研判与协调，执行人员负责侦察、调查和接触信息来源。主管可以建议人选，具体派谁仍由玩家选择。其他职责的执行编制、并发及任意主管独立取代专门执行人员的范围尚未确定。

正式出使设一名主执行人。玩家可选择主管或相关人员随行，并明确各人具体工作、目标、投入与授权；主执行身份不复制所有成员能力。随行保留原正式岗位，不建立第二岗。出发前提示原岗可能延后的工作，由玩家安排；不自动补任、不改建筑配置，也不让同一人在国内外同时完成冲突的现场工作。人物只能获得与自己实际参与或获准告知有关的信息，参加同一使团不等于共享全部秘密。

岗位按适合自身的人口、建筑或科技条件组合逐步开放，条件提前可查，不统一要求三项同时达标。解锁与任命分开，不自动补人、不强制设满，也不锁住玩家原有操作；不默认必须先有主管才能执行既有任务。

调任可以立即进行，或安排当前任务完成后进行。立即调任交出旧岗，明确旧任务如何处理及何时到任；不瞬间移动人物或暗中改派旧任务。完成任务后调任者，在任务结束前仍任原岗，待办计划不产生第二岗效果。两种方式都保留能力、知识、经历、关系和记忆，不自动指定继任者。

主管空缺时，建筑保留原设置并按基础规则运行，失去离岗者的对应个人效果，不另设全行业统一减产。主管空缺不自动改变已派任务的目标、执行人或预算；需要具名执行者的任务缺人时提示玩家安排，不暗中生成或挑选人物。岗位开放、交接、任务进展与人员位置分别记录。

## 四、人物来源、招募、识人与成长

新人物可来自已有居民、人才来访、他人引荐和贸易、外交、通信等真实跨国往来。来源、身份、履历须与世界历史相容；居民具名化不补造矛盾经历，也不让尚未接触的外国人自动成为已认识对象。普通居民继续群体统计，不要求完整逐人档案。引荐只创造接触机会，不保证能力、品行或加入意愿。

玩家说明拟安排的职责与待遇发出邀请，人物结合处境、关系和诉求，可以同意、拒绝或提出条件。条件未确认不生效；拒绝不自动产生仇恨或永久封锁。接受邀请、在途等进展、实际抵达和正式任命分别记录；已在当地者不凭空增加旅途，原岗位、任务和外国任职也不会因邀请消失。拟任不等于任命，不解锁尚未开放岗位、不自动接管建筑。不新增候选人强制容量或自动补任规则。

准确能力数值与确定档位隐藏。玩家通过已知履历、交谈、推荐理由和持续表现识人；口才、名望、亲近或自信不能直接证明胜任。本人自述、推荐人的评价、可核实事实与实际贡献分别保留。报告区分**玩家要求、实际投入、环境变化、执行过程、最终结果**，避免将缺料失败、他人贡献或有利环境都归到个人能力。

试任、试办先明确目标、授权与投入。正式试任占用一个正式岗位；试办遵守既有岗位和派遣条件，不借此允许任意未任职者代替执行岗或开放并发。单次表现只提供相关经历与证据，不鉴定全部能力，也不默认到期自动转正、免职或接管建筑。

成长来自实际工作、共同任务、交流学习和有投入的培养，依据真实承担、接触、理解、运用与反馈判断；成功与失败都可能形成收获。经验熟悉不等于五项能力全面提升，未参与的环节不自动学会，听过不等于掌握。简单重复不保证持续成长，复杂任务也不因难度标签固定发奖；重复指令、闲聊、重读或重生成台词不算新经历。

玩家决定培养方向与必要投入，人物依任务和处境落实，遇到资源不足或公务冲突时提出问题。普通交流学习可以自主发生，公共支出和正式派遣仍需玩家确认，不增加导师制度、训练营、专属培养建筑、技能树或性格重塑机制。

新任者可通过交接、熟悉资料和相关人员协助适应，也可直接上任并承担初期不熟悉对准备、沟通、耗时或结果稳定性的影响。交接只传递实际掌握并告知的信息；时间过去不保证已经理解。协助者保留原岗，体现投入时间及原工作影响，不自动兼任、替任或获得新权限。专业收获与感谢、竞争、误解等关系后续分别判断，学到方法不保证成为朋友。进步仍由玩家从实际表现与已知经历判断。

加入、调任或未被录用都不清空已经发生的交谈、约定、旧友、外国联系和个人诉求。未录用者仍可成为后续接触对象，但不保证随时能联系或愿意加入。

## 五、处境权衡、诉求与普通离岗

人物依据稳定的性格和价值倾向，结合重点诉求、关系、记忆、本人信息、机会及其认知中的收益、代价和风险选择行为。经历先影响当前情绪、判断与诉求，持续或重大的经历才可能逐渐改变长期倾向；一次挫折不立即反转性格，能力不代表忠诚或善恶。

每人保留少量持续重点诉求，将“想达到什么”与“怎样争取”分开。受阻可以更换方法、等待、延后、降低期待、维持现状、调整目标或放弃，也可能被更重要的诉求取代；不设置不满必然升级至背叛的单一路线。

需要玩家处理的普通请求先表达缘由与期望，有实际期限时说明紧迫性；随后依据回应和真实变化等待、再次沟通、接受替代办法或调整诉求。诉求记录提出者、缘由、关联人物、目标状态、适用的期限或检查条件，以及承诺与兑现情况。听取、同意、安排执行和完成不是同一状态，替代帮助须看是否实际回应问题。

表现不佳时，玩家可以针对原因查证、免职或调任、改善人手设备与预算、表彰补偿、解释谈判、培养或明确目标后观察。这些处理各有实际成本和后果，换人不补设备，补贴不抹失信，谈话不替代物质改善，也不把所有反应统一为好感加减。

因诉求或关系冲突产生普通离岗、辞职时，须有可追溯原因、表达和预告，给玩家处理、调解或安排接替的机会；重复谈话不能无限拖住人物。秘密叛逃按第六节的独立条件处理，不能因此取消普通辞职的预告要求。完整生命周期、退休、自然死亡和代际延续仍属[待审设计](待审设计.md)，本节不批准其细则。

## 六、实际交集、跨国私交与重大越界

共同办公、跨部门议事、联合任务、宴会、私人拜访、熟人介绍和正式会面提供接触机会。人物依性格、诉求、关系、话题和实际处境接近、交谈、回避或帮助；同场不保证人人认识、交谈或成为朋友。后续通过再次合作、通信和拜访延续，关系变化关联实际帮助、责任承担、承诺、误解或争功，双方反应可不同。不要求每类机会都制作独立可操作场景。

人物可自主进行日常交谈、通信、倾诉、建议及寻求支持，原则上安排在公务之外，不逐次要求玩家批准或频繁中断工作。重大私人事务才形成明确请求与公务冲突，玩家可批准、延后、提供替代帮助或拒绝，人物结合理由与落实形成后续。私人活动不授权公费投入、正式派遣或建筑配置变更。

人物可以与外国甚至敌国人物保持私人通信，在已有接触场景中交往；正式出访仍由玩家安排。国家敌对不自动清空私交，外国私交本身也不证明背叛。公开往来按可查范围呈现，隐秘联系通过对话、实际迹象与调查逐步发现，不因系统知道就全知显示。

秘密接触、泄密、叛逃不要求事前公开隐蔽意图。重大越界须具备充分的具体动机、必要接触和真实行动机会，并考虑人物原则及其理解的后果；泄密还须实际掌握所泄内容。不满、低亲近、一次失约或旧友关系不能单独触发越界。同样受到招揽，可以拒绝、报告、隐瞒接触、观望或越界，没有固定升级顺序。

越界允许未经玩家批准真正发生并造成实际后果，须留下可发现迹象，**不保证玩家事前识破**。这不赋予人物改写任免、公共预算、正式派遣或建筑配置的权力；完整秘密行动流程、概率、损失与处罚仍待审，不由现有框架增设伪证、监听、搜查、拘押或刑罚体系。

## 七、情绪、记忆与独立的人际态度

当前情绪与长期记忆分开。人物可以同时存在不同来源的感受，同一经历按各自性格、诉求和理解产生不同情绪；误解能引起真实感受，却不改写事实。情绪关联来源、人物、时间和变化条件，心情恢复不等于遗忘或重新信任。

日常小事逐渐平息，重大帮助、羞辱、背叛或共同危机可由相关人物、话题或情境唤起，不要求每次见面提起。回忆影响当前判断，不重新结算原任务损失、关系奖励或证据；新解释、新行动和新结果可以成为新经历。

真实的正负经历都可累积，影响主动建议、求助或后续做法，仍允许沟通、等待和放弃。重复闲聊、许同一承诺、重读旧记录不能刷取关系。归并日常片段不抹掉多次独立失约，也不把同一事件的多次转述算成多次发生。

| 有向态度 | 含义 |
|---|---|
| 信任 | 是否相信对方、愿意依赖其陈述或承诺 |
| 亲近 | 是否愿意接近、倾诉和维持私人联系 |
| 尊重 | 对其能力、判断或为人的认可 |

三项各自变化，甲对乙与乙对甲分别记录。可以喜欢却不信任、认可能力却保持距离；信任不证明消息真实，亲近不自动取得秘密，尊重不保证意见一致。态度通过交接信息、合作、支持、争功、额外帮助及对话事件发挥作用，关系差不必然怠工，关系好不提高专业水平，不统一换算建筑效率。

朋友、挚友、竞争者等称谓从持续交往和关键经历形成，可以变化、并存和不对称，不设统一亲密等级。亲属、婚姻、师徒身份另记；竞争与怨恨是有经历依据的态度描述，不增加统一数值条。

关系修复对应实际问题：道歉承认伤害，解释澄清需实际传达并被理解，补偿纠正需落实，后续持续守约提供新的可靠经历。查清事实、解决困难与修复关系分别推进，旧历史保留，改善不保证恢复如初。人物对玩家同样适用。

## 八、信息来源、陈述与阶段调查

世界事实、人物所知与判断、人物对外陈述、玩家实际取得的信息分别记录。错误理解或谎言保存在认知与陈述层，不生成真实文件、亲属、成果或已经发生的行动。

公开事务只按公开范围传播，公开不等于全世界即时知情；任命公告不自动透露私下理由和承诺。细节通过参与、告知、通信、工作报告和实际接触取得，参加任务不等于知道所有环节。离岗保留旧知识，但不自动接收原岗新消息；旧信息可过时，新证据须实际传达并理解才可能改变判断。

人物可以误解、带有立场或故意隐瞒。主动撒谎须有具体动机、所知依据与表达机会，不是任意编造历史。亲友推荐可能充分也可能偏颇，对手指控同样需要证据；能力、名望、亲近与自信不保证陈述真实。多人转述同一消息不构成多份独立证据，新材料、不同解释和澄清仍能继续传播。

玩家指定调查对象、具体问题、投入与执行人。问题针对可检查行为，不一次鉴定全局忠诚。执行者在授权内收集、交叉核实并分阶段报告，玩家再决定继续、追加投入、调整方向或结束；无需逐次批准每一次取证。主管建议不自动扩张问题、权限、预算或派遣，报告不自动惩处、免职或调任。

结果可以支持某项行为、反驳具体指控、保留矛盾或暂未证实；未取得证据不等于全面清白，有一条真消息也不证明永远可信。能力、投入、来源和立场影响覆盖与解释，不保证查出全部真相。原始材料、执行人的解释和尚未检查处分别保留。

调查不冻结人物活动，被调查者察觉须有实际原因，不因后台启动秘密调查自动生气。公开指控或知晓朋友参与调查等实际经历可产生后果。事实澄清不抹掉受辱或误解经历，解释、补救与关系修复仍须后续行动。

## 九、双模式对话、行动确认与承诺

接入 AI 时自由交谈，未接入或断线时使用预写台词、情境模板与回应选项；没有 AI 也能完成相同人物互动。两者读取同一人物所知、判断、性格、情绪、关系、记忆、请求和事件状态，切换不丢任务或承诺。AI 负责自然语言表达与意图解析，游戏模拟层维护权威状态，不能用生成文本直接创造历史、资源、关系、授权、任命或已完成行动。

日常可谈近况、工作、人际关系、过去经历、感受、请求和特殊事件，也可表现幽默、赞赏、担忧或怀念；不是每句话都转为资源任务或奖励。人物台词允许第一人称与性格差异，报告采用简洁的世界内措辞，不统一限制为官文书或固定字数。

请求主要采用**同意、拒绝、稍后答复**三个入口。查证、调解和替代办法按事件提供，三入口不取消多方向处理。拒绝不必然决裂，同意不统一发放好感；稍后答复不是确定承诺，也不冻结工作、交往或事件。期限仅来自实际约定与处境，不给所有待办加统一倒计时。

实际拨款、任免、调任、派遣、调查投入等行动先澄清，再展示具体事项、对象、已知代价和执行条件，由玩家确认，经当前条件校验后执行。固定选项与 AI 使用同样规则；普通闲聊直接进行。未确认或取消的提议不支出资源、不改安排、不凭空制造失约，也不删除此前已有承诺。条件不足说明原因，不暗换对象、补预算或自动挑人；确认不等于瞬间到任或完成任务。

听取、同意、明确承诺、开始办理、实际完成分别记录，实际落实才兑现。未来承诺记录对象、事项及实际约定条件或期限，不强制两者同时存在；模糊表态先澄清，不代填金额、阈值、时长或义务。“我听到了”“以后再考虑”不登记为确定承诺。人物可以误解态度与理由，但其期待不改写原始约定。条件达到也不能跳过拨款、任免、派遣等必要确认。

条件变化时可解释并协商延期、调整或撤回。原约定、提出的变更、人物回应及最终落实均保留；新建议不等于新约定，对方可拒绝，也可接受却仍失望。失约结合原因、责任、提前说明与实际损失判断，解释和履约形成新经历而非清空旧史。重复交谈、重生成台词、重读或读档不重复执行动作、发奖或结算同次原始结果。

## 十、事件推进、收束与完整示例

事件采用有条件的情境模板，从真实工作、诉求、关系与经历选择参与者，不固定姓名或预排背叛结局。记录触发与参与条件、关联事实记忆、玩家已知信息、选项成本、即时结果、后续检查、重复限制和结束条件；主体或条件不足不触发。可覆盖任用、事故复盘、合作冲突、家庭困难、承诺和共同历史，但不据此批准生命周期细则。

玩家可主动选择人物与议题发起会谈、共同调解或活动，参与、到场和表达依实际关系、所知、事务与接触机会判断，不保证接受或和解。询问、核对、调解、奖励、调整安排和观察分别处理不同原因，没有一句答复同时查明事实、解决困难并修复所有关系。

暂缓后人物仍工作、交往和调整诉求；后续缓和或恶化需要实际新变化，不能只因没开界面自动升级。事件可以解决、部分妥协、改变目标、撤回或机会过去自然结束，收束不清除旧经历或恢复全部关系。再起相关事件须有新经历或条件，不反复发布同一事项结算。

被动纪事报告已经发生且已知的事实，可介入事件提供实际处理机会。普通进展进入记录，需要决定、已知重要变化或临近实际期限时按同一事项集中提醒。重点关注改变查阅和提示重点，不停止未关注者生活，不借标题、摘要、期限或提醒优先级泄露隐藏联系人与动机。

**完整示例：出使建立私交，通信引出调查。**

1. 玩家任命使节主执行，安排商业主管随行说明贸易条件，明确授权与投入并处理原岗可能延后的工作。各人只影响自己承担的环节，任务记录区分准备、投入、现场表现和环境。
2. 商业主管与外国负责人实际交谈。双方依据言行形成可能不同的评价；回国后可以在已有联系中私人通信，不自动建立国家协议或公费出访。两国后来敌对，私交仍可存在。
3. 对方来信招揽。主管根据原则、诉求、关系、所知和机会，可以拒绝、报告、隐瞒、观望或越界；无条件时不生成泄密，若越界须实际掌握内容、有行动机会并留下可发现迹象，不保证预先识破。
4. 玩家收到可疑往来的报告，只能先知道现有线索。指定调查“是否泄露采购安排”、投入和执行人后，阶段材料可证实来往而仍未知回应；取得真实回信后才可能支持拒绝招揽或泄露该信息，也可能始终没有足够证据。重复转述来信不变成多份独立证据。
5. 玩家可分别询问、继续查证、共同解释或先观察，需要任免和投入时另经确认。公开质问可能让实际获知者感到受辱；证明未泄密不自动修复关系。查清、保留疑点、达成后续安排或请求撤回都可收束，旧经历保留。
6. 后续若有新解释、补救或守约，则分别影响信任、亲近与尊重；唤起旧通信不再结算原损失。AI 关闭后同一事实、承诺与进展继续由台词选项呈现，重要已知结果可进入编年史。

此例说明条件如何连接，不是必经剧情、概率或固定最优选择。

## 十一、运行、持久化与实现边界

完整互动人物的目标规模为国内外合计约 100 名，不是硬上限、固定编制、全居民具名化或已验证容量。普通居民按人口与行业群体处理，首轮具名范围及转换条件另审；外国人物后台使用相同规则持续生活，不因玩家未关注或关闭界面冻结。人物记录与画面对象分开。

| 内容 | 处理原则 |
|---|---|
| 情绪、关系与记忆 | 相关经历、消息和任务事件触发，恢复消退按统一游戏时间推进 |
| 诉求和交往 | 在阶段、处境变化与真实接触机会判断，不逐帧穷举所有人物配对和选择 |
| 通信、任务、调查 | 按抵达、工作完成、取证和报告等节点推进，仅处理相关人物与事项 |
| 经历与证据 | 提取当前相关内容，归并重复日常片段，保留重大恩怨、关键帮助、未兑现承诺与证据；同源转述识别去重 |
| AI 调用 | 仅按展示自由交谈需要调用，日常后台由游戏规则推进，不持续请求每人思考 |

人物、关系、记忆、诉求、承诺和事件用稳定标识引用并持久保存，保存引用与进度，读档不重结算。对话层接收本人可知内容、既有判断与合法动作，不提供未知秘密任意使用；界面和编年史也遵守玩家实际已知范围。状态修改经同一规则入口校验、一次结算并记录原因，校验失败或重复请求不产生额外变化。

处理流程为：**检查真实状态 → 按条件形成事件 → 按本人所知表达 → 校验行动与承诺、确认玩家治理行动 → 模拟层回写结果及原因 → 筛选已知重要结果入史**。日常自主行为和符合条件的秘密行动不统一卡在玩家事前确认上。

实现先建立权威规则、日志与存档，再接两种对话呈现。整体设计完成后验证相同初始状态下两种模式的合法行动一致、控制权不被擅改、关键交往可追溯、读档不重复结算，以及长期存档、加速和多调查并发。频率、归并细则、数据结构、费用和性能预算待验证，不作帧率、内存或 AI 费用承诺；技术接口见[技术与美术](技术与美术.md)。

## 十二、人物 UI 与信息呈现

本节集中人物功能所需的字段与反馈，作为后续制作依据；不新增具体布局、按钮数量或未经审核的面板层级。

| 使用位置 | 需要呈现的内容与反馈 |
|---|---|
| 人物资料与识人 | 身份、来源、现正式岗位、已知履历和成果、推荐理由与已知推荐关系；本人自述、他人评价、核实事实分开；不显示准确能力值、确定档位或最优人选标签 |
| 任命、解锁与调任 | 提前可查的岗位条件、已开放与空缺、具名执行者缺失；旧岗交出、原任务处理、待调任与实际到任分开；不把未完成调任显示成兼岗 |
| 任务与使团 | 对象、目标、投入、授权、主执行人、随行成员与具体工作；出发前提示原岗可能延后事项；报告区分要求、投入、环境、过程、个人贡献与结果 |
| 招募、试任与成长 | 邀请内容、条件和回应，接受／在途／抵达／任命的真实状态；试任试办的目标授权投入；培养方向、实际参与和后续表现，不将拟议、投入或自述当作能力已提升 |
| 对话与请求 | 近况、工作、关系与已知共同经历等话题；同意／拒绝／稍后答复为常用入口，按事件提供查证、调解或替代办法；文字准确表达玩家态度和实际承诺 |
| 实际行动确认 | 展示事项、对象、已知代价和执行条件；确认后显示执行进展、结果或条件不足原因，取消未确认提议不显示已支出或已办理 |
| 承诺与待办 | 实际约定对象、事项、条件或期限，待答复、明确承诺、办理、兑现分别记录；保留原约定、变更、回应和落实，模糊内容先澄清 |
| 关系与经历 | 以已知对话、行为、态度描述和共同经历回顾呈现信任、亲近、尊重及关系称谓；标明人物说法与观察依据，不公开未知内心、隐秘记忆或统一亲密等级 |
| 消息与调查 | 来源、转述／目击等获取方式、发生与获知时间、通信或任务佐证、矛盾与核实进展；原始线索、报告解释、已支持的具体事实与本次暂未证实分开，不全知标注撒谎、忠诚或隐藏联系人 |
| 事件记录与提醒 | 参与者、请求、玩家回应、承诺、实际落实与各方已表达理解；普通进展折叠记录，需决定、已知重要变化和真实期限按同一事项集中提示，可关注人物或事项；未知秘密不通过摘要泄露 |
| 编年史与读档 | 只筛选玩家已经获知的重要结果；保留关键任免、工作、关系与承诺经历，重复展示、模式切换和读档不生成新奖励或新事实 |

人物生活背景与普通居民统计的边界见[人口与聚落](人口与聚落.md)，实际资源成本与结算遵守[贸易与财政](贸易与财政.md)、[产业与建设](产业与建设.md)。事件候选素材与旧参数集中于[参考数值与事件](参考数值与事件.md)，不得据此覆盖本文规则。

**仍待审核**：人物生命周期、自然衰老健康与死亡、退休及代际延续；岗位人数与地区编制、任期、开放条件数值；其他执行岗位、主管独立主执行、任务并发和工作负担；旅途交接与辞职流程时限；人才频率、招募条件成本、试任结束办法；能力与成长参数、培养投入、经验迁移及适应时长；情绪刻度、关系参数、称谓条件、记忆唤起；传播范围时长、调查手段权限成本、秘密行动完整流程与处罚；UI 布局细节和运行预算。统一见[待审设计](待审设计.md)，现有问答和未批准提案不自动生效。
