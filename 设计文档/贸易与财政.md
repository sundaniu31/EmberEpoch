# 贸易与财政

> v1.31 · 2026-10-23。本文统一国家贸易、动态库存、财政及对应 UI。规则已获批准，具体公式、平衡参数和未决处置见[待审设计](待审设计.md)；示例金额不是正式价格。本文不表示游戏或 UI 已实现。

## 1. 国家交易与玩家权限

交易双方是国家，不设独立商队或商人买卖方。原料、半成品、成品原则上均可交易，木板和加工金属可以出售；具体资源清单、禁运和限制另审。

多国参与统一市场，定期报价与撮合。玩家决定允许交易国家、商品、方向、整数数量、限价、预算及出入货聚落，也可明确授权重复规则。人物可建议、影响相关执行结果，不越权持续下单、改目标或改国内连线。其他国家同样受真实人口、经营、计划、库存、金币和承诺约束。

不得同国自买自卖，不设无限金币买家或无限库存卖家；没有真实对手时未成交部分等待或由玩家调整。国内供给格是额定供应配置，贸易交付是真实存在的整数物料，不出售尚不存在的名义产能。生产接口见[产业与建设](产业与建设.md)。

外国未公开的心理区间、库存、国库和计划保持隐藏，玩家依据公开报价、交易、外交和已取得线索判断，不因打开页面就看见对方底价。

## 2. 动态目标库存与补货判断

### 2.1 目标随真实用量增长

每国每项资源分别设安全下限、正常目标、富余上限，作为贸易判断参考，不使用永久固定的几百份目标。

```text
目标储备 = 计划常规用量 × 目标保障周期 + 一次性备料 + 风险缓冲
```

- 计划常规用量包含当前居民粮食及已安排启用的生产投入。暂时缺料导致实耗下降，不代表原需求消失；未启用的闲置设施也不自动按满产采购。
- 一次性备料来自已批准、近期实际要实施的建设等事项，不把所有未来想法同时算成买单。
- 风险缓冲应对应供应、运输等真实不确定性；保障周期、缓冲及三档比例另审。

人口直接增加的居民必需物资目前仅为粮食；其他资源需求来自相关生产、建设和已批准用途。金币多表示支付能力强，不使所有资源目标一起放大。例如每周期用量 20、保障 6 周期为 120；发展到用量 200 时相同周期为 1200。这组数只说明尺度关系。

### 2.2 预测不等于可用库存

未来保障判断结合实际库存、可靠的已成交入货、预计能入库的本地产出、已安排消耗与承诺出口。未成交买单不是可靠入货，名义产能不是已到仓物料；停工、延迟和任务变化会更新预测，不自动改玩家配置。同批建设材料若已算作一次性目标，不在同次缺口计算再扣一次。

全国可以汇总目标，但采购明确入货聚落、出口明确出货聚落。甲城库存不能直接用于乙城，运输仍需时间和运力。公共可用库存、锁定待发货、建筑暂存与在途分别记账，同货不重复计算。可靠在途可减少重复下单，但到货前不能消费、生产或转售。

目标超过仓储容量时显示不足与影响，不靠缩小需求掩盖问题，也不删除溢出货。各聚落库存、总统府仓储、住房和消费规则见[人口与聚落](人口与聚落.md)。

### 2.3 心理买卖区间与数量

| 区间 | 含义 | 愿意成交的数量方向 |
|---|---|---|
| 心理买价 | 舒适买价至最高接受买价 | 越便宜越愿买，仍受真实缺口、预算、容量和运力限制 |
| 心理卖价 | 最低接受卖价至舒适卖价 | 越贵越愿卖，仍受实物、保留需求、承诺和运力限制 |

相对目标越短缺，补货意愿通常越强，也越需要保护现货；越富余，采购意愿通常越低、出口意愿越强。资金紧张限制采购，可能促使出售富余物资，不能凭空造货。价格接受程度与实际成交量同时计算，低价不让无需求国家无限买入。

| 保障处境 | 常见方向 |
|---|---|
| 低于安全下限 | 积极补货，限制继续出口 |
| 安全下限至目标 | 按价格与预算逐步补足 |
| 目标至富余上限 | 主要持有，有利价格可有限调整 |
| 高于富余上限 | 按真实余量出口 |

库存带减少刚买就卖、下一轮再买的反复。每国每资源每轮只选买、卖或等待，不同时生成相反订单。库存带仅是贸易参考，不是生活保留量或居民硬锁；本国默认只提示与建议，不据此自动交易。长期授权的期限与暂停细节另审。

## 3. 共同预算与分轮报价

### 3.1 钱和货都只能承诺一次

```text
采购预算上限／新增可支配资金
= 国库余额 − 已冻结货款 − 项目资金预留 − 近期必要支出保留
```

所有商品共用这份预算，不能每种买单各用一遍全部余额。各类预留互不重复；未到账出口收入不能先花。买量受真实缺口或允许的有限备货、分配预算、目的地仓储与运力约束；卖量受出货地未占用可售实物、保留需求、已有承诺与运力约束。成交前重核真实条件，不能沿用旧 UI 数字重复锁货或花钱。

订单及成交物料使用整数份；未成交部分不扣货、不冻结成交款。单价精度、价格取整、税费和运费另审，不因物料整数就规定所有价格是整数。

### 3.2 游戏时间报价轮

报价按固定游戏时间间隔更新，暂停停止，调速跟随游戏时间。约 10 秒或 5 tick 仅为节奏候选，tick 和周期尚未确定，不采用固定现实 5 秒且不受调速影响的旧口径。

```text
状态快照 → 更新库存目标与心理区间 → 有效订单
→ 市场参考报价 → 撮合 → 成交锁定 → 记录
```

本轮目标和心理区间固定；候选成交价仍检查买方最高价、卖方最低价和对应量。成交后的库存资金变化进入下一轮判断，不能在同轮无限抬价、重算需求、再撮合。

报价压力来自通过真实预算、库存和许可校验的有效买卖量，不能用买不起或无货的意向推价。单轮价格变化须有限制，市场数量表达也须随国家规模发展；具体弹性、区间、基准价、边界、调价公式、撮合排序、同价配给和成交价另审，旧候选集中于[参考数值与事件](参考数值与事件.md)。参考报价不保证立即全部成交。

## 4. 成交、运输与付款

| 状态 | 卖方物料 | 买方资金与物料 |
|---|---|---|
| 未成交 | 按实际安排仍可使用，不重复承诺 | 不冻结未成交部分货款，不视为获得商品 |
| 成交待发运 | 对应实物锁为待发货，不能再卖、生产或消费 | 按实际成交锁价冻结货款，尚未收货 |
| 运输中 | 待发货转在途，不再同时列可用或待发货 | 货款继续冻结，在途不能投入使用 |
| 到货验收 | 该批在途转入目的地库存 | 解付冻结款给卖方，物料成为本地可用库存 |

部分成交只有该部分进入锁货、冻结和运输，余量仍未成交。已锁定批次不按后续参考价改价。未成交单可撤销；成交后取消、退运、变更须根据双方确认和实物状态处理，具体违约规则另审，不允许撤单使在途瞬回、双方各得整批退款与物资。延迟保留真实状态和原因，不自动算到货。

国家贸易只转移实物和已有金币，价格涨跌本身不创造货币。国际交易不设保底对手或隐形补钱。战争损失、保险、赔偿与运输费用仍待审。

总统府控制易手保留本体、公共库存与有效连线，原量转本地新控制方管理；其他聚落、国库和在途不自动转移。成交锁货、待发货、在途与冻结资金继续保留标记，不能借占领解锁重复卖货；具体战时合同归属、履约与违约仍待审，见[军事与占领](军事与占领.md)。普通建筑摧毁损失也只作用于本楼真实物料，不能自动解除其他订单。

### 4.1 粮食的同时点顺序

同一游戏时点实际同时发生时，**合法新出口成交锁货→居民本次消费→有效仓储供粮线按建立先后**。不等待下一报价轮、不倒放早先消费；未成交单不锁货，同粮只锁一次。锁后国内供粮不足按已批准缺粮规则发展，不退回成交量。仓储线顺序在存档、刷新和调额度后保留，不增排序按钮或生活保留量；单条线不足配额时部分交付还是整量等待仍待审。详细权威规则及并发边界见[人口与聚落](人口与聚落.md)。

### 4.2 一批木材的账例

仅为说明状态：甲国木材 100、金币 2000；乙国木材 800且有 120 可售余量。双方合法成交木材 120、单价 5、货款 600，期间无其他收支。

| 环节 | 甲国 | 乙国及货物 |
|---|---|---|
| 锁定 | 木材仍 100 可用；余额 2000 中冻结 600、可用 1400 | 680 可用＋120 待发货，尚未收到 600 |
| 发运 | 木材仍 100；600 保持冻结 | 120 转在途，不重复列库存 |
| 到货 | 木材 220；解付后余额 1400 | 收到 600；在途归零，可用木材仍 680 |

总物料为 900不变；可靠在途进入后续补货预测，不能反复购买同一缺口。

## 5. 贸易 UI：商品行情中心

### 5.1 大面板结构

独立贸易大面板，默认“市场行情”，另有“我的订单”“成交记录”。先选商品，再看本国缺口与各国公开信息，中央突出价格走势和市场数量，库存放在可展开详情。

| 区域 | 内容 |
|---|---|
| 顶部 | 国家贸易标题、可用／冻结金币、下一报价倒计时、三个标签 |
| 左侧商品 | 搜索、关注商品、商品入口；选择后同步中央和下单区 |
| 中央行情 | 参考价、涨跌、走势图、公开买量／卖量／实际成交量、各国公开买卖信息 |
| 右侧下单 | 买／卖、许可国家范围、整数数量、最高买价／最低卖价、出入货聚落、预计支出／收入、预览确认 |
| 库存详情 | 聚落／全国切换，可用、锁货待发货、采购在途、剩余容量，库存三档、保障时长及生活／生产／建设需求依据 |

全国汇总仍表达聚落差异，不掩盖本地短缺。外国隐藏信息不展示。打开页面、查看、筛选、切聚落与预览均不构成下单或修改库存。

### 5.2 图表和数量口径

价格图按报价更新，以游戏时间为横轴；默认参考价，可叠加真实成交价，悬停看时间与数值。无成交时真实成交数据为空，不用参考价补造记录。

公开买量是本轮公开需求，公开卖量是本轮公开供应，实际成交量是已撮合锁定量；都不等于运抵。每轮数量和历史区间成交量注明时间口径，不混为一个数字。时间窗口、图表精度和视觉样式另审。

### 5.3 下单、预览与追踪

```text
选商品 → 看行情 → 选许可国家 → 填数量与限价
→ 选出入货聚落 → 预览确认 → 我的订单追踪
```

物料数量用整数输入和加减按钮。行情超限价时等待，不自动抬价、扩量。预览区分最高货款、预计价格、实际成交金额、实际冻结额：如“木材120，最高价5，最高货款600，运往乙城；成交后冻结相应款，到货后可用”。

卖出预览显示当前已知条件下成交后当地预计剩余可用量、保障程度与居民粮食缺口。未确定税费运费不伪装确定净收益；资金、实物、空间、运输条件不足及保障影响在下单区直接提示，不能藏到折叠详情。成交前估计与成交后实扣、锁货及实际消费记录分开，实时变化须成交时重核。

“我的订单”呈现未成交、部分成交、待发运、运输中、已完成与异常。详情含国家、成交价、数量、冻结款、出入货聚落、运输进度；部分成交及各批数量分别追踪。异常注明已知原因，如限价、可售余量、资金、仓储不足或运输延迟。“成交记录”保留时间、实际价格、数量和交付状态，不能以一个“成功”同时代替成交和到货。

### 5.4 后续 UI 制作依据

保留大面板、三个标签、商品搜索与关注、中央行情、折叠库存、整数限价下单、确认及分批追踪这些交互。页面不得透出外国隐藏心理价，不得擅改授权、限价、国内线或订单实物状态。分辨率、控件、配色、字体、图标、动效和最终实现框架后置。

## 6. 国库、税收和金币来源

主要统计国库，不逐人建立钱包，也不另设居民群体资金池。税收与工资通过简化国内经济表达；账目可核国库来源去向，不宣称整个未逐人模拟的经济严格货币守恒。外国也遵守真实经营约束，未公开财政仍隐藏。

```text
实际税收 = 有效经营税基 × 税法档位系数 × 实际征收比例
```

综合税基来自实际就业及完成的生产、服务，不把就业税、每道工序全产值税、每次入库税层层叠加。空岗不形成对应税基，缺料停工按实际经营下降；搬运、调运、重复入库、政府拨款、发工资及增加军人数本身不产生额外税基。计税如需估值采用相对稳定基准，加工扣投入价值，防止木材→木板→成品全额反复计税；国际报价不能即时抬高税基刷税。

税法保留轻税、常税、重税、临时免税的档位方向。重税提高当期应征与群体负担，实际长期收入还受经营、生活和民意影响，不保证无限增收。减免注明对象、期限、预计减少，应征／减免／实收分别可查。缴金币税不再扣同一批实物，实物税未引入。具体系数另审。

总统府承担基础财政管理，不以银行为征税前提。各国统一金币，开局资金是一次性；税款标实际依据，外交赠款／赔款标付款国家和到账状态，特殊收入标来源条件。不自动贷款、增发或补助；银行管理、征收组织、结算服务仅为候选功能，建成、用工、升级不直接产钱。汇率、信贷、货币发行另审。

## 7. 四类实际花费与用途归集

| 实际支出 | 支付内容 | 发生依据 |
|---|---|---|
| 人员报酬 | 工人、公职、科研、施工、士兵与将领等报酬 | 实际任职、用工时间 |
| 设施维护 | 建筑设备日常保养服务 | 设施存在与实际运行；停用保留成本另定 |
| 贸易采购 | 购买外国粮食、原料、半成品、装备等 | 成交冻结，到货实际支付 |
| 专项支付 | 外交差旅、线人、招聘、奖励、补贴、赈济等具体事项 | 玩家批准对象、用途、代价、条件与时间后支付 |

这四类是实际扣款入口。军费、建设费、科研费、外交费是同批明细的用途汇总，不再收一笔同额总费。材料、装备和实物礼物消耗真实库存，不按市价再买一次；批准预算是授权上限，不是立即花完整额度。

### 7.1 报酬只按真实占用一次

普通报酬可汇总，空岗不按满员计薪。保留岗位的缺料等待仍领报酬，停工不自动解雇；停用后具体费用另审。施工调入人员的同段时间不再在原岗付第二份工资。具名人物一人一正式岗，随任务不增第二基础工资，明确的差旅或奖励另入专项。

军事回营不等于复员，途中及到达仍按真实军事占用；复员实际完成后才释放。军人沿现有人口归属计一次粮食，不能因行军、交战、军费用途又扣军粮或取外国库存。无训练费，也不用“准备费”变相恢复训练。

### 7.2 维护、维修、重建分别核算

维护金币对应日常保养服务；若以后含物料耗材要明确列量与取得方式，不能同项暗中金币加实物双扣。普通建筑材料维修仅扣当地公共可用材料，不占维修劳力、不增维修金币或工资，不能重新包装为修缮服务费。原有报酬与日常维护仍按真实状态记账，不因维修凭空免除或加倍。队列、缺料／受袭暂停及恢复原设置见[军事与占领](军事与占领.md)。

毁楼损失的是本楼真实暂存及批次，已投入不退也不重复扣，不按市价再扣金币；重建采用建设规则，不沿用旧维修进度。总统府控制易手保留本体，不产生总统府重建费用。住房缺口只通过既有维修、新建解决，不另设临时安置费用；两者的材料、施工人手与报酬区别继续保留。

### 7.3 实物消耗不构成第二笔采购

进口木材到货已经支付采购款，加工时只扣实际木材及正常报酬、维护，不再把原料折成另一笔金币采购。科研报酬与维护不等于购买科技点，实验材料仍扣实物。专项承诺、预留和实际发放分别留记录，重复打开对话／预览不重复支付。人物请求与承诺见[人物与社会](人物与社会.md)。

## 8. 余额、预留与财政不足

国库余额包含仍持有的冻结款，冻结不是已付，却不可再用。项目预留与近期必要支出保留相互排除，同一用途只占一次。实际支付减少余额并释放对应预留；贸易到货解付减少余额、解除冻结，不再重复扣。

```text
期末国库余额 = 期初余额 + 实收税款 + 已到账贸易收入 + 其他已实现收入
             − 实付人员报酬 − 实付设施维护 − 实付贸易采购 − 实付专项支付
```

冻结和预留不再入实际支出账；预计税收、未到账卖款、未实现事件收入仅作预测。持续税费依游戏时间，暂停不推进，调速不改单游戏时间金额，季／年报只汇总实发，不再发一轮税、扣一轮全年工资。计费步长、精度、取整另审。

界面提前显示近期付款义务、缺口及依据。玩家可改预算、减少新增项目、改税法或安排真实贸易。已发生未付款列待付，不消失，也不挪冻结货款补缺。欠薪、维护不足需原因与发展过程，期限、部分支付、恢复和后果另审；不默认负金币、借债、自动卖库或改产业线。

## 9. 财政 UI 与账例

| 信息组 | 必备字段 |
|---|---|
| 资金总览 | 余额、冻结、项目预留、近期支出保留、新增可支配资金 |
| 实际收入 | 税款、已到账贸易及其他有来源收入；税基、减免、实收可查 |
| 四类支出 | 同笔明细仅计一次，物料另列 |
| 用途汇总 | 军事、建设、科研、外交等；明确为同批明细视图 |
| 收支判断 | 经常收支差额，贸易／一次性单列，实际与预测分开 |
| 待付提醒 | 到期义务、未付款、预计缺口与原因；不公开未知外国账 |

行动确认分别显示金币、物料、占用劳力和预算预留，不能让金币替代缺材料。财政具体页面布局与控件规格尚未定。

余额1000、冻结200、近期保留300时新增可支配500，余额仍1000；随后实收税250、实际支付已保留300后，余额950、300预留释放、200仍冻结，可支配750。预留、释放与实付各记真实变化，不重复加减。
