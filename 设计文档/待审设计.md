# 待审设计与长期方向

> 设计基准 v1.31 · 2026-10-23。本文件保留旧稿中仍有价值但未完成本轮确认的方向，集中列出参数空缺。它不向已确认系统增加自动生效规则；冲突时以对应现行专题为准。

## 1. 下一步：不足额仓储交付

已确认的同刻粮食顺序为新出口合法成交锁货→居民本次消费→加工供给线按建立先后。尚未确定：余粮不足一条线本次配置量时，是先交付已有整数数量，还是等待凑齐；如何处理后续线路、未交付数量是否以及怎样持续记录。不可由实现人员默认为小数均分、自动改额度或以后加倍追发。完整边界见[人口与聚落](人口与聚落.md)。

## 2. 经营参数与人口运输

| 主题 | 仍须确认 |
|---|---|
| 时间 | 游戏年季长度、倍率、消费/生产/报价等调度间隔与统一单位换算 |
| 人口 | 年龄健康分组、可劳动条件、出生迁入速度、人均粮食、流失群体与相应用工释放 |
| 缺粮与住房 | 缺口与时长计算、人口变化和效率参数、恢复速度；住房容量、等级及对出生迁入的作用曲线 |
| 迁移 | 从本地迁出后的去向、接收条件、跨国与跨聚落衔接，不凭空给另一城市加人 |
| 建设 | 完整建筑材料与用工、开工或分阶段投入、工期、暂停取消、升级上限与成本 |
| 生产 | 完整物料配方、标准周期、暂存容量、仓储出入库能力；供给不足细则不得破坏整数配置和真实库存 |
| 仓储运输 | 总统府容量升级、其他聚落行政载体、满仓处置；运力来源、载具道路、用工、损耗、截获与目标失效 |
| 食品 | 科技解锁的食品清单、生产和替代关系；当前不增加多项必需消费 |

已有贸易安全目标不是居民专用保留量，也不是仓储容量；价格和需求不能以固定小库存或无限现金替代真实条件。

## 3. 科技、材料与尺度

保留旧主方案的自然工艺突破、大学定向孵化、贸易外交获得、逆向研究和遗迹探索等科技来源方向。技术发现、普及与应用可分层，技术图谱用于查来源、年份、条件和覆盖，不恢复点击按钮直接购买科技树。

原案的核心链条继续保留：产线记录连续运行与中断，稳定实践形成可传播的配方、部件或方法“技术种子”，发现时不立即给全国产线统一加成。技术经道路、学者、贸易、缴获或人才流动传播，各聚落拥有各自普及程度；推广由玩家确认投入人员、图纸、时间和材料，不暗中抽调其他产线。尺度闸门依据文明已达到的生产、技术覆盖和人口等实际状态开放，不只看经过多少年。具体突破条件、传播速度、推广成本和闸门阈值仍须审核。

科技应受知识、实际材料和生产能力三方面约束；基础、战略和特定地域材料可以产生贸易与扩张动机。技术解锁不生成装备，仍须实际生产或采购。具体突破机会、大学投入、普及方式、材料消耗与研究停滞阈值未定，不能照抄旧概率、季度增幅或“87%”示例。

保留外交交流、间谍获取、人才流动、保护研究及破坏竞争项目等候选交互。学者暗杀、研究暂停和防永久封锁的戒备上限属于候选玩法，不因整理文档成为已批准行动，须与人物所知、真实动机机会和战争规则共同设计。

尺度愿景为村庄、帝国、行星、星云、宇宙，复用资源—人口—组织—人物的基本语法；轨道战、跨星系航行、稀有科幻材料和宇宙对手后置。旧×1/2/4/8/16科技倍率、阶段人数、面积、固定单局时长均未重新校准，不承诺每一尺度都有独立完整玩法。

世界程序生成、开局前文明史预模拟，以及一层星系加一层星区保留为原案方向；预模拟长度、生成成本、地图层级切换和首期范围须另审。殖民对象设定仍未定，不因沿用“殖民”名称预设所有地区无人或采用同一种居民处置规则。

## 4. 治理、政策与群体民意

保留职业/社会群体×地域的聚合民意方向，与个人情绪、有向关系分别记录。过去条件、邻群体待遇和已形成期望可影响诉求；玩家应能了解已知原因并有适用的回应手段。个人不满不直接变成全行业减产或家族集体报复。

旧候选税法、市场管控、粮食贸易、土地、军役、宗教文化和外交条约七类政策及离散档位保留为讨论清单，不在当前自动实现完整制度。税基和四类费用已有框架，但税率、收入分配、工作人员报酬标准、拖欠和破产后果、银行服务及金币发行细节仍待审。

群体的抗议、停工、迁移、叛乱等应有组织、实际处境和行动条件，不强制按统一等级升级。旧“民意=100−相对剥夺”、泄压概率式、六级民怨、固定两季升级及政策影响矩阵均属候选，阈值、单位与上限未核定，不能套用到个人系统或覆盖现有玩家指挥权。

规模压力可来自维护、道路、沟通、信息延迟和组织成本；量化指标及行政区划待定。不恢复容量超限自动交权、零任免权或家族垄断建筑。总统/民主等政体、贵族世家政治、阶层派系及政策差异尚待整体治理讨论。物种与文化族群可分开考虑，语言、习俗、信仰、职业传统、迁入人口构成、跨族群关系和文化同化保留为候选方向，不自动赋予统一能力倍率或敌意。

## 5. 人物生命周期与扩展

已有年龄增长、健康、年老去世、离任留痕、亲属与无亲属新人才更替的回答和提案，但完整生命周期尚未批准写入现行规则。亲属身份不自动继承职位、私人关系或国家承诺；未来具体继承、未竟事务和代际内容须另行审核。

现有五项通用能力、性格名望分离、一人一岗、岗位解锁方向已确定；权重、阈值、成长速度、适应时长、事件频率和首轮名单未定。约100名完整人物是规模目标，不是固定编制、硬上限或已测得性能。

## 6. 战争、占领与外交后续

| 已有框架 | 还需确认 |
|---|---|
| 真实居民、固定装备、科技解锁兵种、无训练 | 兵种与技术清单、配装比例、人数、征募集合和异地移动时长、补员复员与旧装备回收 |
| 四命令、固定驻扎/追击点、返回不自动攻击、受阻定期重寻 | 射程、速度、追击驻扎距离、重寻间隔与预算，命令具体选择交互 |
| 每弹独立飞行碰撞 | 友伤、穿透、弹丸之间碰撞及具体命中模型，不能默认用抽象命中替代已确认的逐弹判定 |
| 总统府控制条归零本地易主 | 控制值、恢复量、其他聚落行政形式、兵营管理、正式吞并、国界与国家政治归属 |
| 锁货与冻结款项标记保留 | 战时合同所有权、履约、违约赔偿，不自动取消或转移全国国库 |
| 普通建筑损伤、材料维修、被毁全损 | 伤损阈值、材料批量/速度、脱战检测、易主后的维修授权；在途物料遇目标被毁的处置 |

电脑军团战术十状态已确认，但国家层面的宣战决策、战略目标生成、战争迷雾与侦察制度尚未完整设计。旧稿的殖民统治、抵抗与身份制度、结构性国家偏好、外交手段和国家经营AI保留讨论方向，不恢复旧固定阈值或年度行动表。不得以战术状态机已经存在为由假定这些系统也已实现。

## 7. 季节、星球与环境

远端旧稿保留“固定四季、星球体现气候强度、长周期寒冷用事件”的轻季节方向，可供后续讨论。不能直接沿用旧15现实秒/季、春夏秋冬产率或固定冻死人口：当前统一时钟尚待换算，居民必需消费只确认粮食，独立粮仓已取消。

农业季节曲线、取暖木煤、温室、小冰期、疾病道路和工资平滑等应分别确认后接入现有生产、库存和财政；目前不额外自动扣燃料或把冬季当人口必死条件。不保留被否决长季节方案的整段推导及现实天文数字作为游戏规范。

## 8. 编年史、文明指纹与终局

保留以重要实际经历筛选编年史、从局中决策形成文明特征、灭国时形成文明终史的方向。候选文明指标可涉及权力、信仰、经济和扩张倾向，具体数值维度、打分、终局判词和非军事胜利未定。

玩家可自由回档；是否支持跨局回顾、地图尺度转换和更复杂仪表盘另审。故事模板服务于真实状态，不能因“文明指纹”强制命令或泄露未知秘密。

## 9. 实现与验证后置

团结引擎和 CPU Jobs/Burst＋GPU绘制的已确认技术边界见[技术与美术](技术与美术.md)。具体最低配置、FPS、同屏上限、性能预算、GPU弹丸计算及碰撞扩展待实现期测试；不默认迁移ECS、安装新包或改引擎。

旧固定点、完整快照与增量日志/回放、多人、Mod接口、云服务、复杂分析仪表盘等只能在架构评审后确定。当前单机优先，存档应保留实际状态、命令、稳定标识与一次结算记录；是否采用某个特定存储方案不由旧草稿决定。

设计完成后再建立可验证模型与原型。未来重点检查：资源人口守恒、时间暂停调速一致、配额与实际交付分开、AI与无AI同规则、事件可归因、隐藏信息不泄露、读档不重发奖励、低画质不改变真实战斗。旧30局/8类结局/80%等验收数值以及人月估算不作为本轮承诺。

## 10. 后续协作方式

每步先提问，收到回答后提出具体方案，用户批准后才更新规则与UI说明。整理和发布不等于批准待审设计，也不等于同步实现游戏。参数候选和事件素材集中在[参考数值与事件](参考数值与事件.md)，避免逐文件复制历史状态。
