## 1. 单位与候选使用边界

连续游戏时间可暂停、调速；季度、年度是时长、统计或已明确的周期，不额外重复结算产消。库存、交付、人口与有效供给格用整数，生产进度可连续累计；旧小数库存显示、固定现实秒报价不恢复。

已批准的生产尺度示例：同一标准周期中伐木场一级／二级／三级为 1／2／4木材，木板厂为木材 2→木板1、4→2、8→4。周期具体时长未知，**不能与本册每岗每游戏年产率直接叠加**。已批准的财政、军团和贸易例子也只证明记账结构，不确定岗数、军队比例或价格。

旧数值原则曾采用每岗每年 1.0–3.0、单岗最终产出不超过基准3倍、观察30年等范围。这些是候选约束，不否定已批准的等级规模翻倍。旧固定资源容量、人口硬上限、农业直接产人、银行产钱、训练、家族产业与任职硬门槛均不恢复。

### 4.2 心理价与市场公式素材

旧远端公式只提供后续比较思路，未实现本版双区间、动态三档库存、共享预算与运输付款；不能直接替换[贸易与财政](贸易与财政.md)。

```text
稀缺度 = 目标库存 / max(1, 当前库存)
现金紧张度 = max(0, 1 − 金币 / 年支出)
WTP = 基准价 × (1 + α×稀缺度 − β×紧张度)
WTA = 基准价 × (1 − γ×库存充裕度 − δ×紧张度)
旧买意向 = 缺口 × clamp((WTP−当前价)/WTP×弹性, 0, 1.5)
旧卖意向 = 盈余 × clamp((当前价−WTA)/WTA×弹性, 0, 1.5)
旧调价 = 当前价 × [1 + 灵敏度×(有效买量−有效卖量)/(有效买量+有效卖量+平滑常数)]
```

“库存充裕度”、舒适价区间、零年支出保护、分母／价格边界、无交易回归是否采用均待定。保留价随价格平滑改变意愿是素材，不能用无预算／无货意向制造需求压力。旧按比例配给、预算复核后第二轮配给、市价单当轮作废／限价跨轮保留等属于待审撮合分支；现行合法成交仍锁货冻结、到货付款，不能旧公式一算就瞬时换库存。

| 参数 | 旧候选 |
|---|---|
| 基准价（粮／木／煤／铁） | 1／1.2／1.5／2.5 |
| 商品弹性（同序） | 0.6／0.8／0.9／1.3；远端04另给通用1.0 |
| α／β／γ／δ | 0.8／0.5／0.3／0.2 |
| 灵敏度／平滑常数 | 0.05／20 |
| 单轮变化 | ±12%；旧 Demo另有±25%／年，未确认新周期 |
| 总价格边界 | 基准价0.45–2.60倍 |
| 市场深度／价差 | 60；卖出溢价5%、买入价差15%，均不作无限兑换接口 |
| 无成交漂移 | 向基准价6%／年，未定 |
| 时序候选 | 用户约10秒或5tick；旧1秒tick／60tick年／贸易5秒不随倍速等固定映射已停用 |

后续需观察震荡、紧缩、逼仓、缺口重复下单及后期量级，不能用固定几十份交易上限掩盖规模增长。粮食安全库存只是贸易参考，不变成生活硬锁。

民意比较可参考自身过去、邻群体和已形成期望，方向式“民意＝100−相对剥夺”尚无单位定义。群体行为候选式为“不满×组织度×导火索×(1−威慑)／行为成本”，未定概率上限；不直接用于个人情绪、血缘或家族。

旧六级升级素材为微词（旧效率−5%）、不满、骚乱、叛乱、独立、灭国；“两季未回应就升级”的固定触发尚未批准。每个行为仍要有实际主体、动机、机会和可操作回应，不由低数值直接生成哗变、逼迫放权或必然死亡。

## 6. 群体民意候选模型与事件调度

群体的短期情绪 S、长期怨恨 G 与个人情绪、信任／亲近／尊重分开，不设家族集体条。本节是旧事件册 v0.2 的候选方案，**全部阈值、公式、频率和容量待审**，不限制已批人物事件与玩家主动会谈。

| 项 | 旧候选 |
|---|---|
| S／G范围 | 各0–100；S快、G慢 |
| S季度更新 | T＝70−政策压力(0–30)−长期缺口(0–20)；S向T收敛30% |
| G更新 | S<50时＋1，S>75时−1；负面命中＋5–10，正面−3 |
| 显示 | S可见；G通过持续问题线索表达，精确显示方式未定 |
| 启动／间隔 | 初始冷却4季；可抽时55%开抽，抽后冷却2＋随机0–2季 |
| 负面闸门 | G≥30、生效负面数<1＋领土等级、同行业无同类生效 |
| 行业权重 | (G−30)×clamp(在岗人数／100,0.5,2)；档内等概率 |
| 档位 | G<30不入池；30–49轻、50–69中、70–100重 |
| 重复限制 | 旧同行业同事件8季不重复；人名级“一生一次”需逐条审核 |
| 正面 | S≥80且本季无负面，40%抽一行业，冷却4季 |
| 倍率合并 | 同行业取最强，不叠加；跨行业全局总乘数下限0.60 |
| 永久收益冷却 | 旧20季，未定 |

旧稿曾写“G每季最多±3”，又给事件直接＋5–10，作用范围冲突；G＝30时进入门槛但权重为0；全局事件单判与“一季最多一件”关系也未统一。原“平均4–6季一次”的说法只是未经新规则验证的估计，不保证频率。

旧 v0.1“每行业独立掷骰”“民意60以上无负面”“所有事件只能观看不可回应”不恢复；人物的自主行为、可回应请求、调查、主动活动和持续事件均按[人物与社会](人物与社会.md)。候选调度只防信息过载，不以抽中事件代替事实依据。

## 7. 事件素材库（全部未批准）

军事“怠训”已随取消训练停用，不作为候选变相保留。低军队民意不自动触发哗变、逃兵或割据；玩家仍有直接任免和军团指挥权。刺杀不意味着必须等下届选举才能补岗，个人离开也不直接删除一个抽象人才点。库存损失需确有地点、对象和损毁，不复制战毁扣除。

### 7.3 后续链素材与需改写部分

旧册曾给重事件后1–3季抽后续的候选：

| 前件→后续 | 旧概率／效果候选 | 当前必须保留的边界 |
|---|---|---|
| 抗租→抓人 | 50%；再40%平息G−10／60%其他行业G＋5 | 抓捕是具体行动，不能由旧链代替玩家确认或任意责罚 |
| 塌方→请抚恤 | 60%；抚恤旧国库−5%、G−15／拒绝G＋15 | 具体抚恤显示金额条件；旧“拒绝下季必出重事件”不生效 |
| 罢工→军械短缺 | 40%；旧战力×0.90／1季 | 须经真实产出与装备缺口，不给既有军队无依据重复战力惩罚 |
| 学者出走→他国受益 | 40%；旧技术进度＋1 | 须有实际去向、知识和接收条件，不自动给别国加人才或科技 |

候选“人名级永久退出同条池”只是一种重复限制设想，不代替人物生命周期；死亡、离开与未竟事务的具体处理须单独审核。事件终止不强制接下一条，不能无限串剧情。

### 7.4 表达与数据字段素材

可采用具体行为和先前原因的短奏报，如“矿井塌方，先前支护问题是否有人上报”；人物陈述、已核事实与真相分开，不因报告写了伤亡就自动扣同批人口。旧文案中“死七伤十一”等是叙事示例，非固定伤亡或新增伤员系统。

旧事件数据字段可参考类型Bad／Good、Score负−2至−5／正＋2至＋5、六行业Tags、可重复标记及冷却；原TriggerPhase＝Manual和CooldownDays＝240属于旧工程接口，不确定当前触发实现或季日换算。模拟层保存权威状态与效果，事件呈现引用结果，避免事件库与产量表各持一份真值；具体实现待开发阶段决定。
