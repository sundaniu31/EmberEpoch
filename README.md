## 玩法

10 个拓殖者落在 12×18 的荒地上（216 格），先选一块空地放下总统府，然后决定这个殖民地要发展什么行业。
每个建筑自己吃人、自己占地、自己产东西；玩家不指挥个人，只决定"造什么、给几个人、要不要升级"。

- 资源：粮 / 木 / 煤 / 铁（钱、学识随建筑解锁）
- 建筑：住宅、农庄、伐木场、矿场、军营、大学、银行 + 总统府（四级）
- 前 20 年为拓殖期：移民涌入；人口达到 30 后进入定居期，民意系统激活
- 人口用队列成分法计算（5 个年龄桶 × 男女），有人口结构、生育率、死亡率、迁入与预期寿命
- 居民有短期情绪 S 与长期积怨 G：缺员超两成或饥馑时积怨上涨，管理良好时逐渐消解，G≥30 触发行业事件
