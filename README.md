# EmberEpoch

殖民定居点自动化文明模拟的原型 Demo（纯前端单文件，无依赖）。

- 在线试玩：https://sundaniu31.github.io/EmberEpoch/
- 官网：https://grandpasland.xyz/

## 玩法

10 个拓殖者落在 7×7 的荒地上，先选一块空地放下总统府，然后决定这个殖民地要发展什么行业。
每个建筑自己吃人、自己占地、自己产东西；玩家不指挥个人，只决定“造什么、给几个人、要不要升级”。

- 资源：粮 / 木 / 煤 / 铁（钱、学识随建筑解锁）
- 建筑：住宅、农庄、伐木场、矿场、军营、大学、银行 + 总统府（四级）
- 前 20 年为拓殖期：民意保底、积怨封顶、移民涌入；之后保护取消
- 人口用队列成分法计算（5 个年龄桶 × 男女），有人口结构、生育率、死亡率、迁入与预期寿命
- 每个行业有短期情绪 S 与长期怨恨 G，低民意按节拍器触发负面事件

## 本地运行

直接用浏览器打开 index.html 即可，不需要服务器。
