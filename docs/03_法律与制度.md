# 分册 03 · 岗位与任命

> 对应总案：§4.11（原「法律与制度」，已改为岗位体系）
>
> **本册定位**：玩家是总统，10 个主管替他管事。玩家不能直接指挥家族，只能通过**任命谁、批不批请愿、定什么政策**来影响他们。
>
> **与其它册的接口**
> - 岗位人选 → §07 家族（家族子弟 / 贫民提拔）
> - 行业产能 → §01 建筑
> - 民意汇总 → §07 家族民意
> - 税率、人口政策 → 本册后半（待补）
>
> **状态：岗位名称已定，效果与数值待设计。**

## 2. 明确不设的岗位

| 不设的岗位 | 原因 | 职责归到哪 |
|---|---|---|
| **地区主管** | 层级过多，且与家族民意重复 | 不做 |
| **财政主管** | 收税本质是民怨问题，不是官员问题 | 民怨 → 税收实收率 |
| **治安主管** | 同上 | 民怨 → 犯罪率 |
| **司法主管** | 纠纷做成事件，玩家亲自裁决更有戏 | 随机事件 |
| **工程主管** | 设了反而让玩家少一个预算决策 | 建筑自损 + 玩家出钱修 |
| **设施主管** | 会让岗位数膨胀到 20+，收益低 | 不做 |

## 3. 已定的规则（不含数值）

| 规则 | 内容 |
|---|---|
| **人选来源** | 只有两种：家族子弟 / 贫民提拔 |
| **兼任** | 不允许，一人一岗 |
| **空缺** | 会有后果（待设计） |
| **关键人物上限** | 16（10 在岗 + 6 候补） |
| **人物属性** | 6 个：治理 / 技艺 / 经商 / 学识 / 军事 / 威望 |
| **岗位主属性** | 每个岗位只看一个属性，效果由该属性决定（待设计） |
