## 4.11 法律与制度（框架）

### 4.11.1 三组开关

| 组 | 玩家可调 | 主要影响 |
|---|---|---|
| **税率** | 低 / 中 / 高 | 财政收入 ↔ 民怨 |
| **人口政策** | 封闭 / 常规 / 开放 / 强征 | 人口增速 ↔ 口粮、住房、民怨 |
| **政体** | 集权 / 议事 / 分权 | 经营容量 ↔ 决策延迟、民怨阈值 |

### 4.11.2 设计原则

1. **每条法律都有反向代价**，不存在纯收益的选项。
2. **法律改动有延迟**（如税率调整次年才生效），防止玩家反复横跳。
3. **法律之间互相牵制**（高税率 + 强征移民 = 民怨爆炸）。

### 4.11.3 待补内容

- 立法解锁条件（纪元、建筑、科技）
- 每条法律的副作用条目
