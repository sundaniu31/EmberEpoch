## 4.4 殖民与统治

殖民不是"派个移民过去"，而是一条**完整的链条**：

```
侦察 → 选址 → 先遣队（会死人） → 建立据点 → 通路 → 驻军 → 移民输入 → 产业植入 → 文化处理 → 自治或直辖
```

**三种统治策略**（可在同一殖民地内混合使用）：

| 策略 | 短期产出 | 资源影响 | 抵抗变化 | 长期回报 | 适用场景 |
|---|---|---|---|---|---|
| **掠夺** | ×3.0 | 储量 −5%/月，不可再生 | +8 / 月 | 无。资源枯竭后殖民地废弃 | 现金流紧张、不打算长期占领 |
| **拓殖** | ×1.0 | 稳定 | +2 / 月 | 需持续移民输入，20 年后趋于稳定 | 有富余人口、追求稳定版图 |
| **同化** | ×0.4 | 稳定 | −3 / 月 | 25–40 年后产出反超拓殖，并解锁**该文化专属科技/兵种** | 长线布局、追求独特性 |

**关键张力**：抵抗值和生产效率是**同一条曲线上的两端**。

```
抵抗 0–30：正常生产
抵抗 30–60：产出 −20%，偶发破坏事件
抵抗 60–85：产出 −50%，需要驻军镇压（驻军消耗后勤）
抵抗 85–100：武装叛乱，殖民地暂时脱离控制
```

抵抗值不是纯负反馈，它同时是**同化进度条**：抵抗高的殖民地在被成功同化后，会产出"文化融合"成果（新配方、新兵种、新建筑）。**压得越狠，反弹越大；但反弹过后，融合越深。**

**殖民地的"人"**：每个殖民地有人口池，按身份分三档——**公民 / 契约工 / 奴役**。身份决定产出系数、抵抗增长速率、以及是否可以晋升。玩家可以立法改变身份制度（L4 层操作），这会引发本土阶层的连锁反应。

## 4.5 战争

### 4.5.1 战争的定位

战争是**获取"可自动化资源节点"的手段**，不是目的。因此战争系统必须满足：

- 打赢一场战争，应该让**生产链变得更好**（获得矿脉、港口、人口），而不是只得到一个"胜利"弹窗；
- 打输一场战争，应该让**生产链断裂**（失去补给、失去市场），而不是只掉声望。

### 4.5.2 战斗力的构成

```
战斗力 = 装备产出 × 后勤覆盖 × 士气 × 战术系数
```

**没有"金币买兵"**。军队消耗的是你生产链的产物：

| 纪元 | 军需品 | 后勤形式 | 断粮后果 |
|---|---|---|---|
| 拓荒 | 石斧、火把 | 随身携带 | 立刻溃散 |
| 定居 | 木盾、猎弓 | 村内补给 | 战斗力减半 |
| 城邦 | 青铜甲、战车 | 驮兽运输 | 无法远离本土 |
| 国家 | 铁器、火药 | 补给车队、粮道 | 战线收缩 |
| 帝国 | 火炮、步枪 | 铁路、港口 | 远征军崩溃 |
| 行星 | 装甲、飞机 | 全球物流网 | 战区失控 |
| 星海 | 舰体、能量武器 | 航线、补给站 | 舰队搁浅 |

> **设计意图**：想打仗，先建厂。这直接把战争系统和自动化系统焊在一起。

### 4.5.3 战斗的抽象度随纪元上升

| 纪元 | 战斗呈现 | 玩家操作粒度 | 是否有"自动解决" |
|---|---|---|---|
| 拓荒 / 定居 | 实时小队，5–20 人，可暂停 | 逐个下达移动/攻击 | 否（此时战斗是主要内容） |
| 城邦 / 国家 | 战术地图，百人级，阵型与地形 | 编队指令 | 是（战力比 > 3:1 时可跳过） |
| 帝国 | 战役地图，战线推进（类似突出部） | 划定战线、分配兵力、设定目标 | 是（可全自动） |
| 行星 / 星海 | 战区与舰队编成 | 姿态、编制、跳跃路线 | 是（战略层直接结算） |

**关键**：抽象度上升时，**旧的战斗方式不会消失**。玩家可以在帝国时代下钻到某个村庄，用 L0 的方式亲手打一场 20 人的遭遇战。这在机制上无收益，但在情感上有巨大收益——这是"我记得我当年"的来源。

### 4.5.4 战争的三个阶段

1. **动员**：把民用产线转为军工（自动化规则要重写，L2 层的考验）。转换有延迟，延迟长度 = 你的工业复杂度。
2. **推进**：占领节点 → 建立补给 → 驻军 → 恢复生产。占领不等于控制，控制需要驻军，驻军需要后勤。
3. **消化**：战后处理。三种选择——**割地（治理需求 +）／扶植傀儡（产出 −，但治理需求不增）／人口迁移（本土产能 +，殖民地抵抗 +）**。

> **这一层是本作与《群星》最大的差异**：群星的战争结束于条约，本作的战争结束于"你能不能管住它"。

## 4.8 外交与势力

### 4.8.1 AI 势力的"结构性人格"

不做"侵略性 0.7 / 友善 0.3"这种扁平参数，而是给每个 AI 势力一套**结构性偏好**：

| 类型 | 特征 | 扩张速度 | 抗风险 | 玩家应对 |
|---|---|---|---|---|
| **高度自动化** | 产业链极长、效率极高 | 极快 | **极低**（一处断裂全线崩） | 打击其关键节点，而非正面战场 |
| **低自动化、高冗余** | 大量小作坊、低效但分散 | 慢 | 极高 | 消耗战无效，需斩首或分化 |
| **军事化** | 军工占比高、民用薄弱 | 中 | 中（靠掠夺补给） | 断其掠夺路线，逼其内溃 |
| **商业型** | 贸易网络广、领土小 | 慢 | 高（可迁移） | 封锁航路，或买断其供应链 |
| **宗教/意识形态型** | 认同度高、抵抗强 | 中 | 极高（同化困难） | 无法速胜，只能长期文化战 |

**设计意图**：让玩家学会"读结构"而不是"算数值"。识别对手的结构性弱点，是本作战略层的核心乐趣。

### 4.8.2 外交手段

- **贸易**：交换**产能**而非成品（"我每月给你 200 木材产能，你每月给我 50 铁"）。
- **附庸**：对方保留内政，你获得军事通行与部分产出，但承担其治理需求的一部分。
- **文化渗透**：派"顾问"进驻，缓慢提升对方认同度（类似特洛伊木马）。
- **技术封锁**：不卖某类制品，延缓对方工艺突破。
- **婚姻/人质/条约**：提供"软性"的声望加成。

**禁止项**：不做"外交点数买好感度"的扁平设计。所有外交必须绑定具体利益（产能、人口、通路、技术）。

## 4.9 贸易与价格系统（现货撮合）

> 本节是 §4.8.2「贸易交换产能」的机制展开。系统**只做现货**，不做期货契约。
> 时代背景：冷兵器 / 铁器时代。可交易品：粮、木、煤、铁（学识不可交易）。

### 4.9.1 时间粒度

三层时间轴，各层结算频率不同：

| 层 | 间隔 | 结算内容 |
|---|---|---|
| **tick** | 1 秒 | 资源渐进累积、建造进度、UI 刷新 |
| **月** | 5 tick（5 秒） | **贸易撮合、价格更新** |
| **年** | 60 tick（60 秒） | 人口老化、随机事件、民意、建筑完工 |

- 一年固定 60 tick = 12 个月，**60 必须能被 5 整除**；改动年份长度时需同步检查。
- 倍速只压缩生产与建造层；**贸易固定 5 秒一次，不随倍速加快**，保证玩家有决策窗口。
- 人口的老化只能按年推进；出生与死亡可按 tick 用小数累积，显示时取整。

### 4.9.2 保留价格：斜率而非阈值

每个国家对每种商品维护两个心理价位：**WTP**（最高愿买价）与 **WTA**（最低愿卖价）。二者由库存与现金推出：

```
稀缺度 = 目标库存 ÷ max(1, 当前库存)
紧张度 = max(0, 1 − 金币 ÷ 年支出)

WTP = 基准价 × (1 + α×稀缺度 − β×紧张度)
WTA = 基准价 × (1 − γ×库存充裕度 − δ×紧张度)
```

**核心：保留价不是开关，而是斜率。** 价格越划算，意愿量越大；越接近保留价，意愿量越小——而不是"跌破就买满、高于就一点不买"。阈值模型会让价格在临界点剧烈跳变，斜率模型才产生平滑的价格发现。

```
买意向量 = 缺口 × clamp((WTP − 当前价) ÷ WTP × 弹性, 0, 1.5)
卖意向量 = 盈余 × clamp((当前价 − WTA) ÷ WTA × 弹性, 0, 1.5)
```

### 4.9.3 超额需求定价

```
总需求 D = Σ 各国买意向量 + 玩家买单量
总供给 S = Σ 各国卖意向量 + 玩家卖单量
超额需求 E = D − S

新价 = 当前价 × (1 + 灵敏度 × E ÷ (D + S + 平滑常数))
并钳制在 ±X% 内
```

- E > 0 → 买方占优 → 涨价
- E < 0 → 卖方占优 → 降价
- E ≈ 0 → 势均力敌 → 不动

**唯一例外**：若 D + S 极小（市场近乎无成交），价格不按上式算，改为**向基准价缓慢回归**——避免"无人交易时价格因 D=0 被砸到下限"。

### 4.9.4 每 tick 撮合流程

五个阶段，顺序不可调换：

1. **收单**：AI 按当前价算意向量（受库存与现金双重约束）；玩家读取这 5 秒内挂的单
2. **定价**：按 §4.9.3 算出本 tick 结算价
3. **配给**：可成交量 = min(D, S)，按比例分配给各买方/卖方；预算检查（成交额 × 新价 ≤ 现金），不足则缩减；**第二轮**把释放出来的量再分给仍有预算者
4. **结算**：买方现金 −、库存 +；卖方现金 +、库存 −
5. **收尾**：新价成为下 tick 的当前价；未成交挂单按类型处置

**顺序约束**：必须"用旧价算意向量 → 算新价 → 按新价做预算检查 → 缩减成交量 → 结算"。不可先按新价算意向量，否则会陷入循环。

### 4.9.5 货币守恒（铁律）

**每笔成交，买方支出 = 卖方收入。系统不创造、不销毁货币。**

- 全流程只有「结算」阶段动钱，且买卖成对操作
- 价格变动本身不动钱，只造成**资产重估**（囤货方账面变富），不是货币创造
- **先配给、后扣钱**：若先按报量扣款再退款，任何异常都会导致货币凭空消失或重复计算
- 唯一允许的货币注入/回收：税收（回收）、母国补贴（注入），须单独记账

### 4.9.6 部分成交

| 情形 | 处理 |
|---|---|
| 买方钱够、市场缺货 | 按可供给量比例成交，未成交部分的钱**根本不扣** |
| 卖方有货、无人买 | 货留存，下 tick 继续挂 |
| 新价过高致买方买不起 | 结算前按现金缩减成交量 |
| 大单扫货 | 按比例配给，只成交市场能提供的部分 |

### 4.9.7 挂单机制

| 类型 | 玩家操作 | 成交条件 | 跨 tick |
|---|---|---|---|
| **市价单**（默认） | 只报量 | 按结算价成交 | 作废 |
| **限价单**（可选） | 报价 + 量 | 结算价满足限价才成交 | 保留至成交或撤销 |

AI 国家不保留历史挂单，每 tick 按最新库存与现金**重新报价**（相当于做市商），因此其意向量始终反映当前状态。

### 4.9.8 参数表（待调）

| 参数 | 建议初值 | 作用 |
|---|---|---|
| α 稀缺系数 | 0.8 | 库存少时 WTP 抬升幅度 |
| β 现金系数（买方） | 0.5 | 缺钱时 WTP 压低幅度 |
| γ 库存充裕系数 | 0.3 | 库存多时 WTA 下压幅度 |
| δ 现金系数（卖方） | 0.2 | 缺钱时 WTA 下压幅度 |
| 弹性 | 1.0 | 价格偏离对意愿量的敏感度（决定市场深度） |
| 灵敏度 | 0.05 | 超额需求对价格的推动强度 |
| 平滑常数 | 20 | 防止小市场被单笔交易砸出巨幅波动 |
| 单 tick 价格钳制 | ±12% | 最后一道保险 |
| 单 tick 单商品报量上限 | 待定 | 防止玩家逼仓 |

### 4.9.9 已知风险

| 风险 | 表现 | 缓解 |
|---|---|---|
| **价格震荡** | 价格在均衡点两侧来回跳 | 降低灵敏度、加价格钳制 |
| **通缩螺旋** | 全员囤现金 → 无人买 → 价格跌 → 更想囤现金 | AI 刚性消费保底（粮食），市场不会完全冻结 |
| **玩家逼仓** | 大资金扫货推高价格再反手卖出 | 单 tick 报量上限；「允许但有限」 |
| **参数敏感** | 微调即从一潭死水变剧烈震荡 | 先统一参数跑通，再按国家类型分化 |

### 4.9.10 与既有设定的对齐

- **总案 §4.8.2**：贸易仍是"交换产能"，本节只是把"成交"这一环做成可计算的价格发现过程。
- **纪元分层**：拓荒期（5–30 人）市场只有零星商队、参与者少；城邦期（300+）才形成多国充分竞争的市场。参数可随纪元收紧/放宽。
- **民意系统**：物价飞涨可作为 S 下降、G 上升的来源之一（粮价 > 基准价 1.5 倍时，粮相关行业民意承压）。
- **移民政策**：强征档涌入的低星人口会压低人均产出，进而影响该国的 WTP（买不起），形成"人口多但市场弱"的负反馈。
