# 分册 06 · 季节与星球差异

> **状态：已定稿（轻季节方案）。** 2026-10 定案。
> 结论已并入 01（农业产出）、02（工资平滑）、04（价格乘数）、05（数值表）。
> 本文档保留"为什么这样定"的推导，以及被否决的方案，供后续查阅。

---

## 1. 要解决的问题

1. **要不要加入季节**——农业产出、取暖消耗是否需要按季节波动。
2. **不同星球的季节差异如何表达**——是"季节长度不同"还是"季节强度不同"。
3. 季节加入后，哪些原有系统需要同步修改。

---

## 2. 天文事实（供设计参考）

季节长度由**公转周期**与**轴倾角**共同决定，与距离无关：

| 星球 | 轴倾角 | 公转周期 | 一季时长 |
|---|---|---|---|
| 水星 | 0.03° | 88 天 | 几乎无季节 |
| 金星 | 177°（倒立） | 225 天 | 理论极端，但浓密大气抹平温差 |
| 地球 | 23.4° | 365 天 | 3 个月 |
| 火星 | 25.2° | 687 天 | 约 6 个月（地球时间） |
| 木星 | 3.1° | 11.9 年 | 约 3 年（倾角小，季节弱） |
| 土星 | 26.7° | 29.5 年 | 约 7.4 年 |
| 天王星 | 97.8°（躺着转） | 84 年 | 约 21 年，极端 |
| 海王星 | 28.3° | 164.8 年 | 约 41 年 |

**"冬长夏短"真实存在**：火星轨道偏心率 0.093（地球仅 0.017），南半球夏季约 154 天、冬季约 178 天。土星有类似但更温和的差异。

## 3. 已讨论的三种方案

| 方案 | 内容 | 成本 |
|---|---|---|
| **A 不做** | 农业连续产出，无取暖需求 | 低，但丢掉"熬冬"体验 |
| **B 轻季节** | 只影响农业产出与取暖消耗 | 中 |
| **C 重季节** | 农业 + 取暖 + 疾病 + 道路 + 士气全受影响 | 高，平衡难 |

**倾向 B**：核心幻想里已经写了"第一个冬天冻死了一个人"，不做季节这句话就落空。

---

## 4. 关键冲突：长季节导致恶性循环

如果按星球真实季节长度（如土星 7.4 年/季）设计，测算结果：

| 项 | 数值 |
|---|---|
| 5 人开局，年耗粮 | 5 粮 |
| 冬季 7.4 年所需储备 | **37 粮** |
| 初始粮仓 | 60 粮 |
| 冬季人口继续增长 | 7 年后可达 15–20 人 |
| 20 人 × 7.4 年 | **需 148 粮** |
| 结果 | **第二三年断粮，全员饿死** |

**根本原因**：储备需求 = 季节长度 × 人口消耗，前期既无人口承载力，也无粮仓容量。

### 与原有设计的四重冲突

| 原设计 | 冲突 |
|---|---|
| 1 年 = 60 秒 | 一季 7.4 年 = 7.4 分钟，"年"失去意义 |
| "第一次撑过冬天"（核心幻想） | 那个冬天应是 15 秒的考验，不是 7 分钟的绝境 |
| 农田 25 粮/年、口粮 1 粮/人/年 | 撑 7.4 年需要 7 倍粮仓 |
| 粮仓容量 +500 | 容量上限不足 |
| 人口冬季继续增长 | 消耗上升、储备吃空 → 正反馈死亡螺旋 |

---

## 5. 修正方向：用"强度"替代"长度"

**季节长度固定为 1 年 4 季（每季 15 秒）**，星球差异体现在"季节有多狠"：

| 星球类型 | 冬季产出 | 取暖需求 | 冬季死亡风险 |
|---|---|---|---|
| 温和型 | −20% | 无 | 无 |
| 标准型（地球） | −100%（仅 15 秒） | 每人 0.1 木 | 无 |
| 严酷型 | −100% | 每人 0.3 木/煤 | 缺燃料会死人 |
| 极端型 | 全年 −30%，无四季 | 全年取暖 | 持续损耗 |

**长周期寒冷改用"事件"表达**，不用季节：

```
小冰期（持续 10–20 年）
  全局农业产出 −30%
  取暖需求 ×2
  粮价上涨
```

季节提供年度节奏，气候事件制造"这个时代很难"的记忆——两层叠加，既有星球差异，又不破坏每年一收的农业节奏。

---

## 6. 如果坚持长季节：前置条件

必须同时加入以下之一，否则数值上过不去：

1. **多年生农业**：种一次持续产出，冬季只减产不停产（如冬季 30%），把缺口从"100% × 7.4 年"降到"70% × 7.4 年"；
2. **温室 / 储藏建筑**：让冬季仍有一部分产出；
3. **大幅提高粮仓容量**：容量需 ≥ 季节长度 × 人口 × 1.2。

---

## 7. 若采用"轻季节"，需要改的系统

| 系统 | 改动 | 是否必须 |
|---|---|---|
| 农业产出 | 春 0 / 夏 40% / 秋 160% / 冬 0 | ✅ |
| 粮食库存 | 粮仓从可选变必需 | ✅ |
| 工资 | 按年产出平滑，÷12 每月发（否则冬季农民零收入） | ✅ |
| AI 囤积 | 秋季囤粮、入冬前囤燃料（价格波动自然驱动，不需额外规则） | ✅ |
| 价格 | 季节乘数（冬粮 ×1.15、煤 ×1.3；春季粮价高） | ✅ 已有基础 |
| 取暖 | 冬季每人耗木/煤 | 可选 |
| 施工 | 冬季减速 | 可选 |
| 死亡率 | 冬季上升、缺燃料冻死 | 可选 |

**不建议做**：伐木/采矿冬季减产（变量太多）、维护费冬季加价（太琐碎）。

## 9. 定稿结论（2026-10）

### 9.1 采用：固定四季 + 强度差异

**季节长度永远是 1 年 4 季，每季 15 tick（15 秒）。星球差异不体现在长度上，体现在强度上。**

| 季节 | tick 区间 | 农业产出 | 取暖消耗 | 劳工流向 |
|---|---|---|---|---|
| **春** | 0–14 | 0% | 无 | 农闲，可抽调去伐木/建造 |
| **夏** | 15–29 | 40% | 无 | 少量农活 |
| **秋** | 30–44 | **160%** | 无 | 全员抢收 |
| **冬** | 45–59 | 0% | 每人 0.1 木（标准型） | 农闲，可抽调 |

**年总产出不变**（农田仍是 25 粮/年），只是集中在秋季。

### 9.2 星球差异：四档强度

| 类型 | 冬季农业 | 取暖 | 冬季风险 | 适用 |
|---|---|---|---|---|
| **温和型** | −20% | 无 | 无 | 新手星球 |
| **标准型** | −100% | 0.1 木/人 | 无 | 默认 |
| **严酷型** | −100% | 0.3 木或煤/人 | 缺燃料 → 冻死（每年 2% 人口） | 中后期 |
| **极端型** | 全年 −30%，无四季 | 全年 0.2 | 持续损耗 | 挑战局 |

### 9.3 长周期寒冷：改用事件，不用季节

```
小冰期（持续 8–20 年）
  全局农业产出 −30%，取暖需求 ×2，粮价 ×1.25
```

它与季节是两层：季节提供**年度节奏**，气候事件提供**时代记忆**。

### 9.4 必须同步的三个改动

| # | 改动 | 原因 |
|---|---|---|
| 1 | **农业产出改季节曲线** | 春 0 / 夏 40% / 秋 160% / 冬 0 |
| 2 | **工资按年平滑发放（÷12）** | 若按当月产出发，农民冬季工资为 0，会饿死 |
| 3 | **粮仓从可选变必需** | 秋收是月均的 5 倍，没仓就爆仓浪费；春季最危险 |

### 9.5 明确不做

- 季节性的伐木/采矿减产（变量太多，调不动）
- 季节性建筑维护费（太琐碎）
- 季节性疾病加成（先并入"疫病"事件）
- 按星球改变"一年多少秒"

### 9.6 被否决的方案

| 方案 | 否决原因 |
|---|---|
| **长季节**（土星级 7.4 年冬季） | 储备需求 = 季节长度 × 人口消耗；5 人开局到第二三年必饿死，见 §4 测算 |
| **季节长度随星球变** | 与"1 年 = 60 秒"和"熬过第一个冬天"两条根基冲突 |
| **无季节** | 丢掉核心幻想里"第一个冬天"的体验 |
