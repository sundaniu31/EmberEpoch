## 4.7 人口与社会

### 4.7.1 人口模型

#### 4.7.1.1 算法选型：队列成分法 + 等级比例

**推荐：队列成分法（cohort-component）+ 等级独立比例。**

```
结构：
  年龄 × 性别 = 5 × 2 = 10 个队列（小数，代表人数）
  等级 = 独立比例（一级 85% / 二级 12% / 三级 3%）
```

**为什么不把等级塞进队列**：等级只影响"能干什么活"，不影响生育和死亡。如果等级也进队列，会变成 5×2×3 = 30 个桶，计算和 UI 都翻三倍，收益却很小。等级用比例单独管理，还能被"教育"独立提升，不干扰人口结构。

**UI 三个扇形图**：

| 图 | 内容 | 用途 |
|---|---|---|
| 年龄结构 | 0–14 / 15–29 / 30–44 / 45–59 / 60+ | 看劳动力与抚养比 |
| 性别比 | 男 / 女 | 看生育潜力 |
| 等级构成 | 一 / 二 / 三级 | 看能承接多少高级岗位 |

#### 4.7.1.2 生育

```
新生人口 = 育龄女性 × 基础生育率 × 床位系数 × 性别比系数 × 粮食系数 × 政策系数
```

| 因子 | 规则 |
|---|---|
| 育龄女性 | 15–29 岁女性 + 30–44 岁女性 |
| 基础生育率 | 0.15 / 人 / 年（TFR ≈ 4.5） |
| 床位系数 | 空床≥2：1.0；1：0.7；满：0.35；超员1–2：0.15；超员≥3：0 |
| **性别比系数** | `clamp( min(男,女) ÷ max(男,女) ÷ 0.8, 0.3, 1.0 )` ——男女接近 1:1 时 1.0；比例 4:6 时 0.83；比例 2:8 时 0.31 |
| 粮食系数 | 有余粮：1.0；刚好：0.6；缺粮：0.2；断粮：0 |
| 政策系数 | 鼓励生育 1.3 / 常规 1.0 / 限制生育 0.7 |

> **"合适的年龄 + 合适的男女比例"就是这个公式直接表达的**：女性不够或比例失衡，出生数立刻掉下来。

#### 4.7.1.3 死亡与预期寿命

```
死亡 = Σ(各年龄桶人数 × 该年龄死亡率)
```

| 年龄 | 死亡率/年 |
|---|---|
| 0–14 | 3.5% |
| 15–29 | 1.0% |
| 30–44 | 1.4% |
| 45–59 | 2.8% |
| 60+ | 10% |

- **预期寿命**由当前死亡率反推（生命表近似），在人口页显示。
- 诊所、粮食充足、住房不超员 → 死亡率下降 → 寿命上升 → 人口自然增长加快。

#### 4.7.1.4 等级（首版只做一级）

| 等级 | 能做什么 | 产出系数 | 来源 |
|---|---|---|---|
| **一级** | 农田、伐木场、矿场 | 1.0 | 出生默认 |
| 二级 | + 加工建筑（锯木厂、磨坊等） | 1.5 | 学堂培养（后续） |
| 三级 | + 研究、高级建筑 | 2.0 | 高等学堂（后续） |

- **首版所有居民都是一级**，全部可去一级建筑。
- 高级建筑"不能使用一级居民"——这条规则在高级建筑解锁时才生效。
- 二级/三级的培养放到"学堂"内容里做。

#### 4.7.1.5 劳动分配

- 玩家**逐栋调整雇工人数**（0 到 满员 × 2.5）。
- 总在岗 ≤ 就业人口；调高从无业池拉人，调低退回无业池。
- **无业人口不产出，但照吃粮** → 失业率越高，民怨涨得越快。

#### 4.7.1.6 人口政策（迁入）

| 设置 | 范围 | 效果 |
|---|---|---|
| **安家费** | 0–50 钱 / 人 | 迁入速度 = 基础速度 × (1 + 安家费 ÷ 25) |
| 年龄要求 | 不限 / 青壮优先（15–44） | 迁入量 −30%，但劳动力占比更高 |
| 性别要求 | 不限 / 男 / 女 | 调节性别比，间接影响生育 |

- 迁入前提：**空床 ≥ 3、余粮 ≥ 1**。
- 安家费一次性从国库扣除；给得越多来人越快，但财政压力越大。
- 迁入的人口默认全部为一级。

#### 4.7.1.7 原有描述（保留）

简化版 POP，不做个体模拟，做**聚落级人口池**：

- **人口数**（小数，便于大规模）
- **职业分布**（采集/加工/建造/军务/行政/科研/服务）
- **三个维度**：满意度（0–100）、认同度（对当前政体，0–100）、技能（0–5 级）
- **身份**（公民/契约工/奴役）

职业分配由 L3 管理者或 L2 规则决定，玩家设定优先级与配额——这是"自动化"在社会层的体现。

### 4.7.2 民怨与声望

- **民怨**：居民对生活的真实不满——吃不饱、住不下、干得多拿得少、危险岗位没人管。它直接压低生产效率，累积到顶会引发离走与暴动。
- **声望**：对外的影响力，影响贸易条件、招引移民、结盟与威慑。

**民怨满 = 聚落瓦解**（居民大规模离走、人口断崖），但**可恢复**：补粮、加薪、减负、换掉盘剥的管理者，都能把它压下来。

民怨的来源随发展阶段变化：

| 阶段 | 民怨的主要来源 |
|---|---|
| 拓荒 | 饿肚子、冻死、没地方睡 |
| 定居 | 拥挤、缺医、分配不公 |
| 城邦 | 税重、阶层固化、外来人口受歧视 |
| 国家 | 战争消耗、征兵、粮价飞涨 |
| 帝国 | 边远地区被忽视、管理者盘剥 |

> 民怨是"经营结果的镜子"：它不凭空产生，每一项都能追溯到玩家的某个决定。

### 4.7.3 阶层与派系

三个基础阶层：**生产者 / 中间层 / 精英**。每个纪元名字不同（农奴/市民/贵族 → 工人/中产/资本家 → 技术员/管理者/算法所有者）。

派系不是随机生成的，而是**从玩家的制度选择中长出来的**：
- 你立了"森林保护法" → 出现"林业行会"派系（受益）和"拓荒者协会"派系（受损）；
- 你用了"奴役"制度 → 出现"废奴运动"派系；
- 管理者坐大 → 出现"地方势力"派系。

**派系的力量 = 其成员占人口的比重 × 其掌握的关键资源**。这保证了政治不是独立小游戏，而是经济结构的直接映射。

## 4.3 经营容量（Administrative Capacity）

**这是经营规模的天花板。** 它存在的目的不是惩罚扩张，而是让"打下来"和"管得住"成为两件事。

```
经营需求 = Σ(区域基础需求 × 距离系数 × 文化差异系数)
经营供给 = 政体基础 + Σ(制度等级 × 行政效率) + Σ(管理者管理力)
```

- **需求 > 供给** → 管理开始漏风：税收流失、指令执行不到位、边远区域自行其是。
- **供给 > 需求** → 有盈余，可用于开新区域或提升制度等级。

**关键设计**：经营供给**不随领土自动增长**。占领土地只增加需求，不增加供给。玩家必须通过**建制度、培养管理者、修路缩短距离**来提升供给。

> 一场成功的征服如果没有配套的经营建设，会把帝国拖垮。**打下来只是开始，管得住才是本事**——这是殖民题材最实在的表达。

> 注意：漏风是可修复的。玩家可以缩小版图、加派管理者、升级行政来止损，而不是眼睁睁看着帝国崩掉——**这是经营压力，不是失控惩罚**。
#### 4.7.8 人口市场：结构由规则涌现

全球流动人口不是一个固定数字，而是所有国家行为的加总。

```
① 各国迁出量 = 人口 × 基础迁出率 2% × 政策系数(0.5–2.0) × 压力系数
   压力系数 = 1 + (税率 − 1) × 0.5 + 战争 0.5 + 饥荒 0.3

② 全球流动人口 = Σ 各国迁出量
   年龄/等级结构 = 各国迁出量加权

③ 各国年龄结构（由出生率查表）
   出生率 4.5% → 0–14 占 42%；3.0% → 32%；2.0% → 24%

④ 各国等级结构（由教育覆盖率算）
   升级概率 p = 教育覆盖率 × 5% / 年
   二级概率 = 1 − (1 − p)^(年龄 − 15)
   三级概率 = 二级概率 × 0.25
   一级概率 = 1 − 二级 − 三级

⑤ 教育覆盖率 = min(1, 学堂容量 ÷ 适龄人口)
```

**没有固定市价。** 某细分人群的价格 = 各国出价的竞价结果：

```
AI 出价 = 该国人均产出 × 劳动力稀缺系数 × 类型偏好
玩家出价 = 玩家设定
分配 = 按出价从高到低，直到该细分供给耗尽
```

**两个推论**：

1. 所有国家教育都很好 → 市场上二三级多 → 人才价格自然下降。
2. 战乱国大量输出低教育人口 → 全球一级占比被拉高 → 二三级更贵。

> 这就是"只给规则、结果涌现"在人口系统上的体现：没有任何一处写死"三级占 4%"。
