## 4.7 人口与社会

### 4.7.1 人口模型

简化版 POP，不做个体模拟，做**聚落级人口池**：

每个聚落有：
- **人口数**（连续值，不是整数，便于大规模）
- **职业分布**（采集/加工/建造/军务/行政/科研/服务）
- **三个维度**：满意度（0–100）、认同度（对当前政体，0–100）、技能（0–5 级）
- **身份**（公民/契约工/奴役）

职业分配是**自动的**（由 L3 管理者或 L2 规则决定），玩家只设定优先级和配额。这正是"自动化"在社会层的体现。

### 4.7.2 民怨与声望

- **民怨**：居民对生活的真实不满——吃不饱、住不下、干得多拿得少、危险岗位没人管。它直接压低生产效率，累积到顶会引发离走与暴动。
- **声望**：对外的影响力，影响贸易条件、招引移民、结盟与威慑。

**民怨满 = 聚落瓦解**（居民大规模离走、人口断崖），但**可恢复**：补粮、加薪、减负、换掉盘剥的管理者，都能把它压下来。

民怨的来源随发展阶段变化：

| 阶段 | 民怨的主要来源 |
|---|---|
| 拓荒 | 饿肚子、冻死、没地方睡 |
| 定居 | 拥挤、缺医、分配不公 |
| 城邦 | 税重、阶层固化、外来人口受歧视 |
| 国家 | 战争消耗、征兵、粮价飞涨 |
| 帝国 | 边远地区被忽视、管理者盘剥 |

> 民怨是"经营结果的镜子"：它不凭空产生，每一项都能追溯到玩家的某个决定。

### 4.7.3 阶层与派系

三个基础阶层：**生产者 / 中间层 / 精英**。每个纪元名字不同（农奴/市民/贵族 → 工人/中产/资本家 → 技术员/管理者/算法所有者）。

派系不是随机生成的，而是**从玩家的制度选择中长出来的**：
- 你立了"森林保护法" → 出现"林业行会"派系（受益）和"拓荒者协会"派系（受损）；
- 你用了"奴役"制度 → 出现"废奴运动"派系；
- 管理者坐大 → 出现"地方势力"派系。

**派系的力量 = 其成员占人口的比重 × 其掌握的关键资源**。这保证了政治不是独立小游戏，而是经济结构的直接映射。

## 4.3 经营容量（Administrative Capacity）

**这是经营规模的天花板。** 它存在的目的不是惩罚扩张，而是让"打下来"和"管得住"成为两件事。

```
经营需求 = Σ(区域基础需求 × 距离系数 × 文化差异系数)
经营供给 = 政体基础 + Σ(制度等级 × 行政效率) + Σ(管理者管理力)
```

- **需求 > 供给** → 管理开始漏风：税收流失、指令执行不到位、边远区域自行其是。
- **供给 > 需求** → 有盈余，可用于开新区域或提升制度等级。

**关键设计**：经营供给**不随领土自动增长**。占领土地只增加需求，不增加供给。玩家必须通过**建制度、培养管理者、修路缩短距离**来提升供给。

> 一场成功的征服如果没有配套的经营建设，会把帝国拖垮。**打下来只是开始，管得住才是本事**——这是殖民题材最实在的表达。

> 注意：漏风是可修复的。玩家可以缩小版图、加派管理者、升级行政来止损，而不是眼睁睁看着帝国崩掉——**这是经营压力，不是失控惩罚**。
