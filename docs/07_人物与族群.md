# 分册 07 · 家族、族群与人物

> 对应总案：§1 核心幻想、§4.7 人口与社会
>
> **本册定位**：这是本作区别于其它殖民地经营游戏的核心层。
> **玩家是总统**，家族是"部长 + 民意代表"，族群是文化认同，关键人物是具体的人。
> 宏观层（建筑/人力/法律/对外）决定"这个聚落能不能活"；
> 家族层决定"这些产业谁在经营、民意由谁传递"；
> 族群层决定"这些人愿不愿意一起活"；
> 微观层（关键人物）决定"这个故事记不记得住"。
>
> **与其它册的接口**
> - 族群占比、同化度 → §02 民怨与派系
> - 关键人物职务 → §01 建筑效率、§04 战争指挥
> - 族群职业传统 → §01 行业产出加成
> - 族群语言距离 → §03 行政成本
>
> 数值统一维护在《05 数值总表》。

## 1. 三层四维：为什么必须分层

### 1.1 三个尺度、四个维度

| 尺度 | 维度 | 规模 | 玩家关心什么 | 只有这一维会怎样 |
|---|---|---|---|---|
| **宏观** | 聚落 | 3000–10000 人 | 粮够不够、钱够不够、会不会崩 | 变成 Excel，赢了没有情绪 |
| **中观** | **家族**（利益） | 5–8 个重要家族 | 谁在经营、谁在赚钱、谁在提意见 | 产业成了抽象产能，没人对政策有反应 |
| **中观** | **族群**（认同） | 4–6 个族群 | 这些人能不能处、会不会融 | 变成抽象派系，没有质感 |
| **微观** | 关键人物 | 5–20 人 | 这个人靠不靠得住、他死了怎么办 | 变成小说，管不动生产 |

**任何单层都撑不起"经营一个帝国"的成就感**：
- 只有宏观 → 像《希克斯之歌》，深度够但没人记得住任何一个居民；
- 只有微观 → 像《矮人堡垒》，七个人很有故事，但永远只有七个人；
- 只有中观 → 像《维多利亚 3》，阶级与族群很真实，但你不知道"张老三"是谁。

**家族与族群是正交的两把刀**：

```
家族 = 谁在经营、谁在赚钱、谁会向你提意见   → 利益
族群 = 谁信什么、跟谁一伙、愿不愿意同化     → 认同
```

两者交叉时，才出现真实历史里最典型的结构性矛盾：**某个族群被某个家族长期把持某行业**。

### 1.2 四维的分工

```
宏观层（每年结算）：产量、价格、税收、人口结构
   ↑ 提供"压力"，让玩家的每个决定都有代价

家族层（每年结算）：经营权、利润率、家族民意、请愿
   ↑ 提供"政治传导"，把"民众不满"变成"具体的人来找你谈"

族群层（每季结算）：占比、同化度、关系矩阵、聚居格局
   ↑ 提供"摩擦"，让同样的政策对不同人群效果不同

微观层（事件驱动）：关键人物的能力、忠诚、关系、生死
   ↑ 提供"记忆"，让数字背后有具体的人
```

### 1.3 一条完整的四维链（本作的设计样板）

```
【宏观】粮价从 1.0 涨到 1.6
  ↓
【家族】农业家族利润率翻倍 → 申请扩大经营权 → 总统批地建田
  ↓
【族群】新田占了少数族群聚居区边缘的地 → 该族群家族民意 −6
  ↓
【家族】该家族提"给块地"请愿 → 总统拒绝 → 民意 38→28
  ↓
【人物】该族群的家主（关键人物）忠诚 70→52
  ↓
【宏观】他消极经营，辖区 8 栋建筑效率 ×0.82 → 木材减产 15%
  ↓
【家族】连续两年民意 < 30 → 家主下台，另一个家族接盘
  ↓
【族群】新家族属于主体族群 → 关系 −8，冲突概率上升
```

**这条链没有一环是脚本写死的**，全部由"价格 → 利润 → 请愿 → 民意 → 忠诚 → 效率 → 换人"的状态传导产生。

> 这就是本作的核心竞争力：**别人做宏观博弈或个体故事，本作做"民众的不满如何经由家族变成对总统的压力，再落到具体的人身上"。**

## 2. 文化族群：不是物种，是"汉族这种划分"

### 2.1 两层必须分开

| 层 | 是什么 | 差异体现 | 获取方式 |
|---|---|---|---|
| **物种** | 生物学分类 | 寿命（精灵百年、哥布林十年）、生育率、体型、环境耐受 | **后期事件解锁，非开局选择**；玩家初始均为人类 |
| **族群** | 文化认同 | 语言、习俗、信仰、职业传统、家族结构 | **开局即有**，移民与征服带来新族群 |

**两层正交，互不替代**：

- 一个精灵可以是"北方商路族群"出身，说一口带口音的话，过冬至节；
- 一个人类可以是"山地冶炼族群"，也可能完全同化进主体文化。

> 物种决定"他能活多久、能干什么"；族群决定"他信什么、跟谁一伙、愿不愿意听你的"。

### 2.2 族群的六个属性

| 属性 | 取值 | 影响什么 |
|---|---|---|
| **语言距离** | 0–100（与主体语言） | 行政效率（每 10 点 −1.5%）、同化速度、关键人物晋升概率 |
| **习俗** | 3 个标签（饮食/节庆/婚丧） | 口粮结构（有的族群不吃某种粮）、劳动日（节庆停工）、生育率 |
| **信仰** | 与主体信仰兼容度 0–100 | 民怨基线、容忍度、祭司类人物影响力 |
| **职业传统** | 1–2 个行业，该行业 +15% 产出 | 族群聚居区的产业格局 |
| **家族结构** | 核心家庭（2–4 人/户）/ 大家族（6–10 人/户） | 住房需求、继承方式、迁移意愿 |
| **对外态度** | 排外 ↔ 包容（−100 ~ +100） | 与其它族群的关系基线、通婚率 |

**每个族群不是"随机生成一堆数字"**，而是从一张**文化原型表**里抽 3–4 个标签组合，保证组合有意义：

| 原型 | 典型标签 | 玩法倾向 |
|---|---|---|
| 农耕定居 | 大家族、重节庆、信仰强、职业传统=耕作 | 粮食产出高，但迁移意愿低，被驱逐时损失大 |
| 山地矿工 | 核心家庭、信仰弱、职业传统=冶炼、排外 | 矿场与冶炼强，但难同化，容易形成独立街区 |
| 商路游民 | 核心家庭、包容、职业传统=商贸、语言距离低 | 贸易效率高，同化快，但忠诚度低、容易再迁走 |
| 河海渔猎 | 大家族、饮食禁忌（不吃某类）、职业传统=渔业 | 早期粮食补充，但受季节影响大 |
| 边地牧民 | 大家族、迁移意愿高、军事倾向 | 兵源好，但定居意愿低，住房需求特殊 |

> **不做固定专名**：族群名由生成器按"地理 + 职业 + 特征"组合产出（如"北岭耕作族群"），不预设"汉族""日耳曼"这类现实名称。

### 2.3 族群从哪来

| 来源 | 时机 | 特点 |
|---|---|---|
| **主体族群** | 开局 | 拓荒队 5 人全部属于它，占比 100% |
| **移民** | 人口政策开放后 | 按全球人口市场的结构带入（见 §02 4.7.4），一次迁入通常 1–3 个族群混合 |
| **征服 / 吞并** | 战争或外交 | 整块聚落连带其族群一起并入，占比可能瞬间到 30%+ |
| **逃亡者** | 事件 | 邻国战乱、灾荒时的难民，通常同化度极低 |

**关键约束**：族群总数上限 6 个。超过就合并（同化度高的两个族群视为融合），避免 UI 爆炸。

### 2.4 同化度（Assimilation）

```
同化度 0–100，每年变化：

+ 混居指数 × 2          （与该族群混住的街区比例，0–1）
+ 通婚率 × 5            （跨族群婚姻占该族群婚姻的比例）
+ 公共设施 × 1          （学堂、市场、祠堂的覆盖，0–3）
+ (主体占比 − 30%) × 0.05   （主体文化越强势，同化越快；主体 < 30% 时变成负数）
− 歧视政策 × 5          （若有针对该族群的政策）
− 聚居隔离度 × 2        （该族群住在自己街区的比例，0–1）
```

同化度的作用：

| 同化度 | 行政效率 | 民怨 | 兵役意愿 | 关键人物晋升 |
|---|---|---|---|---|
| 0–20 | −12% | +8 | 0.5× | 几乎不可能 |
| 20–40 | −6% | +4 | 0.7× | 低 |
| 40–60 | 0 | 0 | 1.0× | 正常 |
| 60–80 | +3% | −2 | 1.1× | 略高 |
| 80–100 | +5% | −4 | 1.2× | 高 |

**重要**：同化度再高，族群身份也不消失。它只降低摩擦，不抹掉差异——这符合现实，也保证了文化多样性不会在中后期被"同化机制"清空。

### 2.5 族群关系矩阵

每对族群有一个关系值（−100 ~ +100），每年变化：

| 因素 | 变化 |
|---|---|
| 通婚 | +2 |
| 同一行业竞争同一岗位 | −1 |
| 资源分配不均（一方明显更穷） | −3 |
| 共同抵御外敌 / 共同渡过灾荒 | +5 |
| 一方享有政策优待 | 另一方 −8 |
| 同化度差距 > 40 | −2（"他们变成我们的人了"） |

关系值的作用：

| 关系 | 后果 |
|---|---|
| > +50 | 通婚率上升、文化融合、可组建混编军队 |
| −30 ~ +50 | 正常，偶有摩擦 |
| < −30 | 冲突事件概率上升（每季 8%）；聚居区开始物理隔离 |
| < −60 | 可能爆发族群暴动，或该族群集体迁出 |

### 2.6 聚居：不画在图上，从住房选择里长出来

**不做"族裔街区"这个地块标签**，而是让住房分配自然产生聚居：

```
新居民找床位时：
  同族邻居的空床 → 权重 ×1.5
  异族邻居的空床 → 权重 ×1.0
  → 结果：同族自然聚集
```

于是：

- 早期混居（房少，没得挑）→ 同化快；
- 后期住房充足 → 各自聚集 → 形成事实上的族裔街区；
- 街区一旦形成 → 该族群在本地有"地盘" → 政治影响力上升。

**玩家可以干预**：强制分配住房（混居政策）能把聚居指数压下去，但短期民怨 +5（"凭什么让我搬"）。

### 2.7 涌现：不做"第 N 年爆发族群冲突"

所有族群事件都由三个状态算出来：

```
冲突概率 = f(关系值, 同化度, 资源差距, 占比变化速度)
诉求类型 = f(该族群的特征)
  · 语言距离高 → 要求母语行政/教育
  · 信仰兼容低 → 要求宗教场所
  · 职业传统被压制 → 要求行业配额
  · 占比快速上升 → 要求政治代表权
```

**四条典型涌现路径**：

| 路径 | 触发链 |
|---|---|
| **劳动力输入国** | 开放移民 → 族群 A 占比 15%→35% → 聚居形成 → 要求代表权 → 拒绝 → 关系 −30 → 冲突 |
| **技术断崖** | 少数族群掌握冶炼传统 → 该族群因歧视迁出 → 冶炼产能腰斩 → 铁价上涨 → 军工停摆 |
| **同化成功** | 混居 + 双语行政 + 通婚补贴 → 同化 70 → 行政效率 +3% → 该族群人物进入管理层 → 关系 +45 |
| **文化反噬** | 强制同化（禁母语）→ 同化度表面上升、关系暴跌 → 二代移民既不被主体接纳也不认同母族 → 出现"无根派"事件 |

## 3. 家族：民意的代理人，总统的对手

> **一句话**：玩家是总统，家族是"部长 + 民意代表"。
> 产业由家族经营，民意由家族汇总，诉求由家族提出——玩家决定接受还是拒绝。
> **民意低了家族下台，民意高了家族坐大。两头都是麻烦。**

### 3.1 三个身份

| 身份 | 作用 | 对应机制 |
|---|---|---|
| **民意代理** | 代表某一行业的从业者，汇总他们的不满 | 家族民意值（0–100） |
| **行业经营者** | 承包该行业的建筑，组织生产 | 经营权 + 利润率 |
| **政治对手** | 向总统提诉求，接受则支持，拒绝则反对 | 请愿系统 + 关系值 |

**家族不是玩家的下属，是玩家的谈判对象。** 玩家可以任命、可以罢免，但每次动手都有政治代价。

### 3.2 玩家是总统：权力与边界

| ✅ 总统能做的 | 说明 |
|---|---|
| **任命 / 罢免家族** | 把某行业交给某家族经营；罢免会引发该家族与其他家族的连锁反应 |
| **批准请愿** | 接受、部分满足、拒绝——三种都有代价 |
| **立法** | 税率、人口政策、平权法令 |
| **建基础设施** | 粮仓、道路、城墙、水井（直属，不交给家族） |
| **宣战 / 缔约** | 对外政策 |
| **放贷 / 补贴** | 给某家族钱，换忠诚或产能 |
| **批地** | 家族想扩编，要总统批地；批了占用途，不批价格继续涨 |

| ❌ 总统不能做的 | 为什么 |
|---|---|
| 直接指挥家族怎么经营 | 家族有自己的判断；玩家只能改条件（税、地、价） |
| 无偿没收家族经营权 | 必须补偿或镇压，两者都有代价 |
| 无视民意无限连任 | 支持率过低会触发弹劾 |
| 直接决定民意数值 | 民意是结果，不是开关 |

> **这就是"涌现"的护栏**：玩家改变的是**条件**（税、地、钱、法），不是**指令**。

### 3.3 民意的两级结构

**从"一个全局数字"改成"一群人对你的评价"**：

```
① 家族民意（每个家族一个 0–100）
   代表该行业从业者的满意度

② 全国民意 = Σ(家族民意 × 该家族代表人口) ÷ 总人口
   这就是总统的支持率
```

**家族民意的计算**（每年更新一次，带惯性）：

```
目标值 = 100
  − 税负不满      （税率每超过 1.0 一档，−10）
  − 粮食缺口      （缺口率 × 40）
  − 住房拥挤      （超员率 × 30）
  − 工资过低      （低于同行业均值 20% 以上，−15）
  − 安全不足      （近 3 年遭袭击或战败，−10）
  − 文化歧视      （该家族族群同化度 < 40，−15）
  + 政策优惠      （有针对该行业的补贴或减税，+10）
  + 行业繁荣      （该行业利润率 > 20%，+10）

实际值 = 旧值 × 0.7 + 目标值 × 0.3        // 惯性，防止一年内暴起暴落
```

**为什么要惯性**：民意不是开关。玩家减税，家族不会立刻满意——他们要看到连续两年的好处。

### 3.4 请愿：家族怎么"提意见"

**触发**：某家族民意 < 45，且距上次请愿 ≥ 2 年。

**诉求内容由"最低分项"决定**——家族不会提一个跟自己无关的要求：

| 民意短板 | 诉求 | 接受的成本 |
|---|---|---|
| 税负高 | 减税一档 | 财政收入减少 |
| 粮食不足 | 建 1 座粮仓 / 进口 50 粮 | 木 25 / 钱 50 |
| 住房拥挤 | 建 1 座住所 | 木 8 + 钱 10 |
| 工资低 | 该行业分成比例 +0.1 | 行业利润下降 |
| 安全差 | 修一段城墙 / 扩军 10 人 | 木、铁、钱 |
| 被歧视 | 颁布平权法令 | **主体族群民意 −8** |
| 路太远 | 修 5 格道路 | 木 10 |

**三个选项，没有免费的那个**：

| 选项 | 该家族民意 | 关系 | 代价 |
|---|---|---|---|
| **全盘接受** | +15 | +10 | 全额成本 |
| **部分满足**（打五折） | +7 | +3 | 半额成本；**连续两次部分满足 → 关系 −5**（"你在敷衍我"） |
| **拒绝** | −10 | −15 | 无成本，但可能触发罢工、抗税、迁走 |

> 设计意图：让"拒绝"成为一个**真实可选**的选项。有些诉求（比如平权）会得罪主体族群，硬顶下去可能更划算——但你要承担这个家族的怨气。

### 3.5 家族的四种命运

| 命运 | 条件 | 结果 |
|---|---|---|
| **升** | 民意 > 80 连续 3 年 | 声望 +15，可申请扩大经营权（玩家可批可不批） |
| **坐大** | 民意 > 85 且代表人口 > 30%，连续 5 年 | 开始越权：干预政策、安插人手、要求席位 |
| **下台** | 民意 < 30 连续 3 年 | 家主辞职（60%）或失去代表性（40%） |
| **被兼并** | 家族人口 < 5 或连续亏损 3 年 | 被其他家族吸收，经营权转手 |

**下台的两种走向**：

```
A 家主辞职（60%）→ 家族内部换人，新家主能力随机，民意重置到 50
                    "新官上任三把火"，但能力可能差很多
B 失去代表性（40%）→ 另一家族接管该行业，原家族降为小家族
                    玩家可以提前扶持接盘者，也可以临时找人
```

**坐大之后玩家有三条路**：

| 手段 | 效果 | 代价 |
|---|---|---|
| **拉拢** | 给特权/联姻，关系 +20 | 该家族更强，其他家族不满 |
| **制衡** | 扶持竞争家族 | 花钱，且可能养出第二个巨头 |
| **打压** | 拆分经营权 / 罢免 | 该家族关系 −40，其他家族恐慌 −10 |

**极端情况**：某家族民意 > 90 且代表人口 > 40% 且玩家支持率 < 30 → **政变**，玩家被赶下台（进入结局或降权模式）。

### 3.6 经营权，不是所有权

与"家族拥有产权"的方案相比，这里采用更轻的**家族承包经营**：

| 项 | 规则 |
|---|---|
| **产权** | 归国家（玩家），所以不能买卖、不能抵押 |
| **经营权** | 由玩家授予某家族，可收回（有代价） |
| **收益** | 家族拿产值的 50% 作为工资与利润，国家拿税收 |
| **投入** | 家族自己出钱维护、升级；国家可补贴 |
| **退出** | 家族可主动放弃经营权（经营不善时常见），国家需另找经营者 |

**为什么不做"家族所有权"**：那会引入"买卖产业、地价、抵押"一整套系统，且与"玩家是总统"的定位冲突。经营权已经足够产生"这田是张家在种"的质感。

### 3.7 家族 × 族群

每个家族属于一个族群。两者交叉时，产生真实历史里最典型的矛盾：

```
某族群家族垄断某行业 + 该族群同化度低
→ "这行都是他们的人" → 阶级矛盾 + 民族矛盾叠加
→ 其他族群民怨 +，关系 −
```

它同时驱动三个系统，不需要新机制：

| 系统 | 反应 |
|---|---|
| 民怨 | 其他族群家族民意 −（"凭什么他们占着"） |
| 族群关系 | 关系 −3/年 |
| 关键人物忠诚 | 该族群管理者忠诚 −（"我的人在给别人打工"） |

**反过来**：玩家为了平衡，把某行业交给少数族群家族 → 主体族群家族民意 −8。**没有无代价的选择。**

### 3.8 生命周期与代际

```
兴起（1–2 代） → 鼎盛（2–3 代） → 分家 / 衰落（3–4 代）
```

| 阶段 | 判定 | 行为倾向 |
|---|---|---|
| **兴起** | 经营 < 3 栋，家主 < 40 岁 | 拼命干，接受低利润，民意容易高 |
| **鼎盛** | 3–8 栋，声望 > 60 | 守成、要特权、抵制新竞争者 |
| **分家** | 家主死亡 + 子女 ≥ 2 且关系 < −20 | 经营权拆 2–3 份，各自经营 |
| **衰落** | 连续亏损 3 年 或 绝嗣 | 放弃经营权，族人外流 |

**代际性格权重**（不写剧本，只给概率）：

| 代际 | 能力期望 | 风险偏好 | 对总统的态度 |
|---|---|---|---|
| 第一代（创业者） | 中 | 高 | 感激（"是你给了我们这摊事"） |
| 第二代（守成者） | 中高 | 低 | 讲规则、要特权 |
| 第三代（败家子） | 低 | 高（赌） | 轻慢、可能抗税 |

> "富不过三代"是一条概率曲线，不是剧本。玩家可能遇到能干的第三代，也可能眼看着它把家业败光。

### 3.9 四条典型的涌现路径

| 路径 | 链条 |
|---|---|
| **政策反噬** | 玩家加税 → 农业家族民意 60→38 → 提"减税"请愿 → 玩家拒绝 → 民意 28 → 罢工 → 粮食减产 → 粮价涨 → 玩家被迫减税（但已经晚了一年） |
| **家族坐大** | 玩家扶持某家族压粮价 → 该家族民意 90、代表人口 35% → 开始要求席位 → 玩家制衡 → 该家族关系 −40 → 消极经营 → 粮食减产 |
| **族群裂痕** | 主体族群家族垄断矿业 → 少数族群家族民意长期 35 → 连续请愿被拒 → 举族迁出 → 带走冶炼技术 → 铁产能腰斩 |
| **接盘真空** | 某家族突然绝嗣 → 该行业无人经营 → 产能 −40% → 玩家临时找小家族接盘 → 新家族能力差 → 连续亏损 → 再换人（循环 3 年才稳定） |

### 3.10 数量与叙事分层

| 层 | 数量 | 有无故事 | 呈现方式 |
|---|---|---|---|
| **重要家族** | 5–8 | 有家主、有世代、有恩怨、有请愿记录 | 家族面板 + 编年史 |
| **小家族** | 10–20 | 只有名字、行业、规模 | 列表一行 |
| **散户** | 其余人口 | 无 | 统计量 |

**叙事节制**：只有重要家族触发请愿与事件文本。小家族只在破产/被兼并时打一行日志。

## 4. 关键人物：让数字背后有人

### 4.1 三层人口

| 层 | 人数 | 有名字 | 有属性 | 有故事 | 计算方式 |
|---|---|---|---|---|---|
| **关键人物** | 5–20 | ✅ | 完整 | ✅ | 个体对象 |
| **骨干** | 100–300 | 编号 + 职业 | 部分（等级、技能） | ❌ | 轻量对象 |
| **大众** | 其余 | ❌ | ❌ | ❌ | 队列里的一个小数 |

**这条分层是"万人规模"与"每个人有故事"能同时成立的前提**：
一万人不可能都有名字，但 20 个人可以。玩家心疼的是那 20 个，不是那 9980 个。

### 4.2 关键人物从哪来

| 来源 | 条件 | 说明 |
|---|---|---|
| **拓荒元老** | 开局 | 开局 5 人全部是关键人物，每人有完整属性 |
| **晋升** | 骨干任职满 5 年 且 能力 > 60 | 从"骨干"升为"关键人物"，有名字、有故事 |
| **出生** | 关键人物子女成年（15 岁） | 继承部分属性，可能有"父辈声望"加成 |
| **事件** | 名匠来访 / 流亡贵族 / 退役军官 / 难民营中的医者 | 一次性加入，自带背景 |

**上限 20 人**：超过时，最老或最不活跃的自动"退居骨干"（不再逐事件追踪，但仍在人口里）。

### 4.3 属性

| 类别 | 属性 | 说明 |
|---|---|---|
| **身份** | 姓名、年龄、性别、族群、等级 | 姓名按族群语言生成 |
| **能力** | 治理 / 军事 / 学识（0–100） | 决定他能干什么 |
| **性格** | 忠诚 / 野心 / 勤勉（0–100） | 决定他会不会背叛、会不会偷懒 |
| **特质** | 2–3 个（正负面） | 如"铁腕""宽厚""酗酒""精算""怯战" |
| **关系** | 配偶、子女、师徒、仇敌 | 关系会传导忠诚与能力 |
| **职务** | 无 / 管理者 / 指挥官 / 学者 / 匠师 / 祭司 | 决定作用 |
| **履历** | 任期、功绩、事故 | "他建了第一座磨坊""他守住了西门" |

### 4.4 职务的实际作用（必须落到机制，不能只是装饰）

| 职务 | 管辖 | 效果 | 空缺后果 |
|---|---|---|---|
| **管理者** | 一片建筑（3–10 栋） | 产出 × (0.7 + 治理/100 × 0.5)，即 0.7–1.2 倍 | 该片产出 ×0.75 |
| **指挥官** | 一支军队 | 战斗结算 × (0.8 + 军事/100 × 0.4) | 战斗力 ×0.7 |
| **学者** | 学堂 / 研究 | 科技速度 × (0.8 + 学识/100 × 0.4) | 科技速度 ×0.7 |
| **匠师** | 一类建筑 | 该类建筑升级成本 −10%~−25% | 无（只是失去折扣） |
| **祭司** | 一个族群或全城 | 民怨 −3/年，同化 +1/年 | 无 |

**管理者是最重要的一个**：他让玩家能"管得过来"，也让他成为最危险的一个人（野心高 + 管辖多 = 坐大）。

### 4.5 忠诚、野心与背叛

```
忠诚每年变化：
+ 薪资高于同类 20% 以上        +3
+ 他的族群同化度高             +2
+ 他被公开表彰                 +5（一次性）
− 他的族群受歧视               −6
− 他的建议被连续否决 3 次       −4
− 同族人物被清洗               −15（一次性）
− 野心 > 70 且管辖 > 5 栋      −3
```

| 状态 | 条件 | 表现 |
|---|---|---|
| 忠诚 | > 60 | 正常履职，偶尔提出建议 |
| 离心 | 20–60 | 效率 −10%，可能私下经营自己的势力 |
| 背叛 | < 20 且野心 > 60 | 带着管辖的建筑/军队自立，或投敌 |

**这不是随机事件**，而是玩家行为的累积结果：你歧视他的族群、驳回他的建议、不给他加薪——他会记账。

### 4.6 死亡

| 死因 | 触发 | 概率 |
|---|---|---|
| 老死 | 超过族群预期寿命 | 按年龄曲线 |
| 病死 | 疫病事件 / 缺医 | 事件驱动 |
| 战死 | 随军出征 | 战斗结算 |
| 事故 | 矿难、火灾、建造事故 | 事件驱动 |
| 被杀 | 仇敌、政变、刺杀 | 关系 < −60 时可能 |

**死亡的三重后果**：

1. **职务真空**：管辖的建筑产出立刻 ×0.75，直到有人接替；
2. **关系断裂**：他的子女、徒弟、仇敌的关系网重组（可能引发连锁）；
3. **情感锚点**：葬礼触发一次全城事件，民怨 −5（"他为我们做过事"），并写入编年史。

> 玩家会记住"那个干了十二年的老农"，因为他有名字、有履历、死的时候全城送葬。
> 这就是"关键人物"层存在的唯一理由。

### 4.7 人物在家族中的位置

关键人物不是孤立个体，他首先是**某个家族的成员**：

| 位置 | 说明 |
|---|---|
| **家主** | 家族的关键人物，通常是该家族经营产业的管理者；一个家族只有一位家主 |
| **继承人** | 家主的子女，成年（15 岁）后进入候选池 |
| **族人** | 普通成员，多数是骨干或大众，不单独追踪 |
| **外姓** | 招婿、过继、雇佣的管家——能力可能强，但忠诚基线低 10 |

**继承规则**（家主死亡或下台时按序判定）：

```
① 有成年子女 → 长子/长女继承，能力 = 父母均值 × 0.8 ± 15
② 无子女 → 兄弟/姐妹继承，能力 −10%
③ 无近亲 → 招婿/过继（若有）→ 家族延续但声望 −15
④ 都没有 → 绝嗣，经营权交还国家，另行分配
```

**分家**：子女 ≥ 2 且彼此关系 < −20 → 家主死后经营权拆成 2–3 份，各自经营。产能分散、互相压价——这是"富不过三代"的机制来源之一。

**自立门户**：非家主的族人若能力 > 75、野心 > 70，且家族经营的产业 > 5 栋，有概率带着 1–2 栋经营权独立，成为新家族。玩家可以提前给他一个特许权来安抚，也可以看着他分裂。

> 家族是容器，人物是内容。人物死了，容器还在（继承）；容器裂了（分家），人物各奔东西。**故事就在这两者的错位里产生。**

## 5. 四维咬合：五条必须存在的传导链

### 5.1 宏观 → 家族 → 民意（压力变成话语）

```
粮价上涨 → 口粮不足 → 农业家族民意下降 → 提"进口粮食"请愿
→ 总统接受（花钱）或拒绝（民意继续跌）
```

**这条链是"民意"的具体化**：民意不是一张仪表盘，是**某个具体的人拿着一份具体的诉求来找你**。

### 5.2 民意 → 家族命运（政治的淘汰机制）

```
某家族民意连续 3 年 < 30 → 家主下台 → 家族内部换人 或 失去代表性
→ 新家主能力随机 → 产能波动 → 价格波动
```

**换人不是"重置"，是"抽卡"**：新家主可能更能干，也可能更差。玩家要提前准备接盘方案。

### 5.3 家族 → 宏观（经营权集中度决定供给弹性）

```
某行业 70% 的经营权集中在 1 个家族 → 该家族惜售/消极经营
→ 供给收缩 → 价格飙升 → 总统限价 → 该家族减种 → 长期供给更少
```

**同样是"粮价涨"，分散经营和集中经营的反应完全相反**：前者各家扩产压价，后者一家惜售抬价。玩家必须学会看**经营权结构**，而不只是看价格。

### 5.4 家族 × 族群（结构性矛盾）

```
主体族群家族把持矿业 + 该族群同化度低
→ 少数族群家族民意长期 35 → 连续请愿被拒 → 举族迁出
→ 带走冶炼技术 → 铁产能腰斩 → 军工与建筑同时停摆
```

### 5.5 微观 → 宏观（人物反作用）

```
关键管理者死亡 → 8 栋建筑 ×0.75 → 木材减产 → 木价上涨 → 建房停滞 → 人口增长放缓
```

**这五条链是本作"独特性"的技术定义**：

| 删掉哪层 | 后果 |
|---|---|
| 删掉家族 | 民意退回抽象数字，玩家看不到"谁在不满"，也失去了请愿这个核心交互 |
| 删掉族群 | 第 4 条断裂，所有家族变成纯经济单位，没有"人"的冲突 |
| 删掉人物 | 第 5 条断裂，家族变成抽象公司，没有面孔 |

## 6. 玩家的手段（每条都有代价）

**家族相关的手段见 §3.2（总统权力）与 §3.4（请愿三选项）；本节只列族群手段。**

| 手段 | 效果 | 代价 |
|---|---|---|
| **混居政策** | 同化 +2/年，关系 +1/年 | 短期民怨 +5，住房分配效率 −10% |
| **族裔自治街区**（默认） | 民怨低，该族群满意度 +10 | 同化慢，长期形成"国中之国" |
| **双语行政** | 语言距离影响减半 | 行政成本 +15%，需要学堂 |
| **通婚补贴** | 通婚率 +，关系 +2/年 | 每年每对补贴 2 钱 |
| **歧视政策**（限某族群） | 主体族群民怨 −5 | 该族群关系 −8/年，同化 −5/年，可能暴动 |
| **族群代表制** | 关系 +5/年，冲突概率减半 | 经营容量 −10，决策延迟 1 年 |
| **强制迁移** | 立刻降低该族群占比 | 声望 −15，关系 −40，国际影响 |
