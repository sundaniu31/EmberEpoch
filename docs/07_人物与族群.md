# 分册 07 · 人物与族群

> 对应总案：§1 核心幻想、§4.7 人口与社会
>
> **本册定位**：这是本作区别于其它殖民地经营游戏的核心层。
> 宏观层（建筑/人力/法律/对外）决定"这个聚落能不能活"；
> 中观层（文化族群）决定"这些人愿不愿意一起活"；
> 微观层（关键人物）决定"这个故事记不记得住"。
>
> **与其它册的接口**
> - 族群占比、同化度 → §02 民怨与派系
> - 关键人物职务 → §01 建筑效率、§04 战争指挥
> - 族群职业传统 → §01 行业产出加成
> - 族群语言距离 → §03 行政成本
>
> 数值统一维护在《05 数值总表》。

---

## 1. 三层叙事：为什么必须分层

### 1.1 三个尺度的问题

| 尺度 | 人数 | 玩家关心什么 | 如果只有这一层会怎样 |
|---|---|---|---|
| **宏观** | 3000–10000 | 粮够不够、钱够不够、会不会崩 | 变成 Excel，赢了没有情绪 |
| **中观** | 4–6 个族群 | 这些人能不能处、会不会闹 | 变成抽象派系，没有质感 |
| **微观** | 5–20 个关键人物 | 这个人靠不靠得住、他死了怎么办 | 变成小说，管不动生产 |

**任何单层都撑不起"经营一个帝国"的成就感**：
- 只有宏观 → 像《希克斯之歌》，深度够但没人记得住任何一个居民；
- 只有微观 → 像《矮人堡垒》，七个人很有故事，但永远只有七个人；
- 只有中观 → 像《维多利亚 3》，阶级与族群很真实，但你不知道"张老三"是谁。

### 1.2 三层的分工

```
宏观层（每年结算）：产量、价格、税收、人口结构
   ↑ 提供"压力"，让玩家的每个决定都有代价
中观层（每季结算）：族群占比、同化度、关系矩阵、聚居格局
   ↑ 提供"摩擦"，让同样的政策对不同人群效果不同
微观层（事件驱动）：关键人物的能力、忠诚、关系、生死
   ↑ 提供"记忆"，让数字背后有具体的人
```

### 1.3 一条完整的三层链（本作的设计样板）

```
【宏观】粮价从 1.0 涨到 1.6
  ↓
【中观】口粮配给收紧 → 主体族群优先保障 → 少数族群 A 的民怨 +8
  ↓
【微观】族群 A 的管理者（关键人物）忠诚从 70 掉到 52
  ↓
【宏观】他管辖的 8 栋建筑效率 ×0.82 → 木材减产 15%
  ↓
【中观】族群 A 聚居区开始有人迁出 → 该区占比从 28% 降到 21%
  ↓
【微观】迁出的人里有一个干了十二年的老匠师——他的作坊空了
```

**这条链没有任何一环是脚本写死的**，全部由"价格 → 配给 → 民怨 → 忠诚 → 效率 → 迁徙"的状态传导产生。

> 这就是本作的核心竞争力：**别人做宏观博弈或个体故事，本作做"宏观压力如何落到具体的人身上，再由这些人反弹回宏观"。**

## 2. 文化族群：不是物种，是"汉族这种划分"

### 2.1 两层必须分开

| 层 | 是什么 | 差异体现 | 获取方式 |
|---|---|---|---|
| **物种** | 生物学分类 | 寿命（精灵百年、哥布林十年）、生育率、体型、环境耐受 | **后期事件解锁，非开局选择**；玩家初始均为人类 |
| **族群** | 文化认同 | 语言、习俗、信仰、职业传统、家族结构 | **开局即有**，移民与征服带来新族群 |

**两层正交，互不替代**：

- 一个精灵可以是"北方商路族群"出身，说一口带口音的话，过冬至节；
- 一个人类可以是"山地冶炼族群"，也可能完全同化进主体文化。

> 物种决定"他能活多久、能干什么"；族群决定"他信什么、跟谁一伙、愿不愿意听你的"。

### 2.2 族群的六个属性

| 属性 | 取值 | 影响什么 |
|---|---|---|
| **语言距离** | 0–100（与主体语言） | 行政效率（每 10 点 −1.5%）、同化速度、关键人物晋升概率 |
| **习俗** | 3 个标签（饮食/节庆/婚丧） | 口粮结构（有的族群不吃某种粮）、劳动日（节庆停工）、生育率 |
| **信仰** | 与主体信仰兼容度 0–100 | 民怨基线、容忍度、祭司类人物影响力 |
| **职业传统** | 1–2 个行业，该行业 +15% 产出 | 族群聚居区的产业格局 |
| **家族结构** | 核心家庭（2–4 人/户）/ 大家族（6–10 人/户） | 住房需求、继承方式、迁移意愿 |
| **对外态度** | 排外 ↔ 包容（−100 ~ +100） | 与其它族群的关系基线、通婚率 |

**每个族群不是"随机生成一堆数字"**，而是从一张**文化原型表**里抽 3–4 个标签组合，保证组合有意义：

| 原型 | 典型标签 | 玩法倾向 |
|---|---|---|
| 农耕定居 | 大家族、重节庆、信仰强、职业传统=耕作 | 粮食产出高，但迁移意愿低，被驱逐时损失大 |
| 山地矿工 | 核心家庭、信仰弱、职业传统=冶炼、排外 | 矿场与冶炼强，但难同化，容易形成独立街区 |
| 商路游民 | 核心家庭、包容、职业传统=商贸、语言距离低 | 贸易效率高，同化快，但忠诚度低、容易再迁走 |
| 河海渔猎 | 大家族、饮食禁忌（不吃某类）、职业传统=渔业 | 早期粮食补充，但受季节影响大 |
| 边地牧民 | 大家族、迁移意愿高、军事倾向 | 兵源好，但定居意愿低，住房需求特殊 |

> **不做固定专名**：族群名由生成器按"地理 + 职业 + 特征"组合产出（如"北岭耕作族群"），不预设"汉族""日耳曼"这类现实名称。

### 2.3 族群从哪来

| 来源 | 时机 | 特点 |
|---|---|---|
| **主体族群** | 开局 | 拓荒队 5 人全部属于它，占比 100% |
| **移民** | 人口政策开放后 | 按全球人口市场的结构带入（见 §02 4.7.4），一次迁入通常 1–3 个族群混合 |
| **征服 / 吞并** | 战争或外交 | 整块聚落连带其族群一起并入，占比可能瞬间到 30%+ |
| **逃亡者** | 事件 | 邻国战乱、灾荒时的难民，通常同化度极低 |

**关键约束**：族群总数上限 6 个。超过就合并（同化度高的两个族群视为融合），避免 UI 爆炸。

### 2.4 同化度（Assimilation）

```
同化度 0–100，每年变化：

+ 混居指数 × 2          （与该族群混住的街区比例，0–1）
+ 通婚率 × 5            （跨族群婚姻占该族群婚姻的比例）
+ 公共设施 × 1          （学堂、市场、祠堂的覆盖，0–3）
+ (主体占比 − 30%) × 0.05   （主体文化越强势，同化越快；主体 < 30% 时变成负数）
− 歧视政策 × 5          （若有针对该族群的政策）
− 聚居隔离度 × 2        （该族群住在自己街区的比例，0–1）
```

同化度的作用：

| 同化度 | 行政效率 | 民怨 | 兵役意愿 | 关键人物晋升 |
|---|---|---|---|---|
| 0–20 | −12% | +8 | 0.5× | 几乎不可能 |
| 20–40 | −6% | +4 | 0.7× | 低 |
| 40–60 | 0 | 0 | 1.0× | 正常 |
| 60–80 | +3% | −2 | 1.1× | 略高 |
| 80–100 | +5% | −4 | 1.2× | 高 |

**重要**：同化度再高，族群身份也不消失。它只降低摩擦，不抹掉差异——这符合现实，也保证了文化多样性不会在中后期被"同化机制"清空。

### 2.5 族群关系矩阵

每对族群有一个关系值（−100 ~ +100），每年变化：

| 因素 | 变化 |
|---|---|
| 通婚 | +2 |
| 同一行业竞争同一岗位 | −1 |
| 资源分配不均（一方明显更穷） | −3 |
| 共同抵御外敌 / 共同渡过灾荒 | +5 |
| 一方享有政策优待 | 另一方 −8 |
| 同化度差距 > 40 | −2（"他们变成我们的人了"） |

关系值的作用：

| 关系 | 后果 |
|---|---|
| > +50 | 通婚率上升、文化融合、可组建混编军队 |
| −30 ~ +50 | 正常，偶有摩擦 |
| < −30 | 冲突事件概率上升（每季 8%）；聚居区开始物理隔离 |
| < −60 | 可能爆发族群暴动，或该族群集体迁出 |

### 2.6 聚居：不画在图上，从住房选择里长出来

**不做"族裔街区"这个地块标签**，而是让住房分配自然产生聚居：

```
新居民找床位时：
  同族邻居的空床 → 权重 ×1.5
  异族邻居的空床 → 权重 ×1.0
  → 结果：同族自然聚集
```

于是：

- 早期混居（房少，没得挑）→ 同化快；
- 后期住房充足 → 各自聚集 → 形成事实上的族裔街区；
- 街区一旦形成 → 该族群在本地有"地盘" → 政治影响力上升。

**玩家可以干预**：强制分配住房（混居政策）能把聚居指数压下去，但短期民怨 +5（"凭什么让我搬"）。

### 2.7 涌现：不做"第 N 年爆发族群冲突"

所有族群事件都由三个状态算出来：

```
冲突概率 = f(关系值, 同化度, 资源差距, 占比变化速度)
诉求类型 = f(该族群的特征)
  · 语言距离高 → 要求母语行政/教育
  · 信仰兼容低 → 要求宗教场所
  · 职业传统被压制 → 要求行业配额
  · 占比快速上升 → 要求政治代表权
```

**四条典型涌现路径**：

| 路径 | 触发链 |
|---|---|
| **劳动力输入国** | 开放移民 → 族群 A 占比 15%→35% → 聚居形成 → 要求代表权 → 拒绝 → 关系 −30 → 冲突 |
| **技术断崖** | 少数族群掌握冶炼传统 → 该族群因歧视迁出 → 冶炼产能腰斩 → 铁价上涨 → 军工停摆 |
| **同化成功** | 混居 + 双语行政 + 通婚补贴 → 同化 70 → 行政效率 +3% → 该族群人物进入管理层 → 关系 +45 |
| **文化反噬** | 强制同化（禁母语）→ 同化度表面上升、关系暴跌 → 二代移民既不被主体接纳也不认同母族 → 出现"无根派"事件 |

## 3. 关键人物：让数字背后有人

### 3.1 三层人口

| 层 | 人数 | 有名字 | 有属性 | 有故事 | 计算方式 |
|---|---|---|---|---|---|
| **关键人物** | 5–20 | ✅ | 完整 | ✅ | 个体对象 |
| **骨干** | 100–300 | 编号 + 职业 | 部分（等级、技能） | ❌ | 轻量对象 |
| **大众** | 其余 | ❌ | ❌ | ❌ | 队列里的一个小数 |

**这条分层是"万人规模"与"每个人有故事"能同时成立的前提**：
一万人不可能都有名字，但 20 个人可以。玩家心疼的是那 20 个，不是那 9980 个。

### 3.2 关键人物从哪来

| 来源 | 条件 | 说明 |
|---|---|---|
| **拓荒元老** | 开局 | 开局 5 人全部是关键人物，每人有完整属性 |
| **晋升** | 骨干任职满 5 年 且 能力 > 60 | 从"骨干"升为"关键人物"，有名字、有故事 |
| **出生** | 关键人物子女成年（15 岁） | 继承部分属性，可能有"父辈声望"加成 |
| **事件** | 名匠来访 / 流亡贵族 / 退役军官 / 难民营中的医者 | 一次性加入，自带背景 |

**上限 20 人**：超过时，最老或最不活跃的自动"退居骨干"（不再逐事件追踪，但仍在人口里）。

### 3.3 属性

| 类别 | 属性 | 说明 |
|---|---|---|
| **身份** | 姓名、年龄、性别、族群、等级 | 姓名按族群语言生成 |
| **能力** | 治理 / 军事 / 学识（0–100） | 决定他能干什么 |
| **性格** | 忠诚 / 野心 / 勤勉（0–100） | 决定他会不会背叛、会不会偷懒 |
| **特质** | 2–3 个（正负面） | 如"铁腕""宽厚""酗酒""精算""怯战" |
| **关系** | 配偶、子女、师徒、仇敌 | 关系会传导忠诚与能力 |
| **职务** | 无 / 管理者 / 指挥官 / 学者 / 匠师 / 祭司 | 决定作用 |
| **履历** | 任期、功绩、事故 | "他建了第一座磨坊""他守住了西门" |

### 3.4 职务的实际作用（必须落到机制，不能只是装饰）

| 职务 | 管辖 | 效果 | 空缺后果 |
|---|---|---|---|
| **管理者** | 一片建筑（3–10 栋） | 产出 × (0.7 + 治理/100 × 0.5)，即 0.7–1.2 倍 | 该片产出 ×0.75 |
| **指挥官** | 一支军队 | 战斗结算 × (0.8 + 军事/100 × 0.4) | 战斗力 ×0.7 |
| **学者** | 学堂 / 研究 | 科技速度 × (0.8 + 学识/100 × 0.4) | 科技速度 ×0.7 |
| **匠师** | 一类建筑 | 该类建筑升级成本 −10%~−25% | 无（只是失去折扣） |
| **祭司** | 一个族群或全城 | 民怨 −3/年，同化 +1/年 | 无 |

**管理者是最重要的一个**：他让玩家能"管得过来"，也让他成为最危险的一个人（野心高 + 管辖多 = 坐大）。

### 3.5 忠诚、野心与背叛

```
忠诚每年变化：
+ 薪资高于同类 20% 以上        +3
+ 他的族群同化度高             +2
+ 他被公开表彰                 +5（一次性）
− 他的族群受歧视               −6
− 他的建议被连续否决 3 次       −4
− 同族人物被清洗               −15（一次性）
− 野心 > 70 且管辖 > 5 栋      −3
```

| 状态 | 条件 | 表现 |
|---|---|---|
| 忠诚 | > 60 | 正常履职，偶尔提出建议 |
| 离心 | 20–60 | 效率 −10%，可能私下经营自己的势力 |
| 背叛 | < 20 且野心 > 60 | 带着管辖的建筑/军队自立，或投敌 |

**这不是随机事件**，而是玩家行为的累积结果：你歧视他的族群、驳回他的建议、不给他加薪——他会记账。

### 3.6 死亡

| 死因 | 触发 | 概率 |
|---|---|---|
| 老死 | 超过族群预期寿命 | 按年龄曲线 |
| 病死 | 疫病事件 / 缺医 | 事件驱动 |
| 战死 | 随军出征 | 战斗结算 |
| 事故 | 矿难、火灾、建造事故 | 事件驱动 |
| 被杀 | 仇敌、政变、刺杀 | 关系 < −60 时可能 |

**死亡的三重后果**：

1. **职务真空**：管辖的建筑产出立刻 ×0.75，直到有人接替；
2. **关系断裂**：他的子女、徒弟、仇敌的关系网重组（可能引发连锁）；
3. **情感锚点**：葬礼触发一次全城事件，民怨 −5（"他为我们做过事"），并写入编年史。

> 玩家会记住"那个干了十二年的老农"，因为他有名字、有履历、死的时候全城送葬。
> 这就是"关键人物"层存在的唯一理由。

### 3.7 继承与家族

- 关键人物的子女成年后进入"候选人"池，能力 = 父母均值 × 0.8 + 随机 ±15；
- 有"父辈声望"：如果父辈功绩多，子女初始忠诚 +10、晋升更快；
- **家族会积累**：三代人都当管理者的家族，会成为地方势力（这既是资产也是威胁）。

## 4. 三层咬合：三条必须存在的传导链

### 4.1 宏观 → 中观 → 微观（压力下沉）

```
粮价上涨 → 配给收紧 → 少数族群民怨上升 → 该族群管理者忠诚下降 → 其辖区效率下降
```

### 4.2 微观 → 宏观（人物反作用）

```
关键管理者死亡 → 8 栋建筑 ×0.75 → 木材减产 → 木价上涨 → 建房停滞 → 人口增长放缓
```

### 4.3 中观 → 宏观（结构反作用）

```
少数族群掌握冶炼传统 → 该族群聚居 → 冶炼产能集中
→ 若该族群迁出/被驱逐 → 全国冶炼产能腰斩 → 铁价翻倍 → 军工与建筑同时停摆
```

**这三条链是本作"独特性"的技术定义**：如果删掉族群层，第 1、3 条断裂，游戏退化成"希克斯之歌 + 名人系统"；如果删掉人物层，第 2 条断裂，退化成"维多利亚 3 的简化版"。

## 5. 玩家的手段（每条都有代价）

| 手段 | 效果 | 代价 |
|---|---|---|
| **混居政策** | 同化 +2/年，关系 +1/年 | 短期民怨 +5，住房分配效率 −10% |
| **族裔自治街区**（默认） | 民怨低，该族群满意度 +10 | 同化慢，长期形成"国中之国" |
| **双语行政** | 语言距离影响减半 | 行政成本 +15%，需要学堂 |
| **通婚补贴** | 通婚率 +，关系 +2/年 | 每年每对补贴 2 钱 |
| **歧视政策**（限某族群） | 主体族群民怨 −5 | 该族群关系 −8/年，同化 −5/年，可能暴动 |
